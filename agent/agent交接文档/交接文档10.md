## 1. 项目是什么

**校内快递配送机器人**（四川师范大学校内无人送餐/快递车）：
- **用户端**微信小程序（18 页）：浏览/加购/下单、微信支付（当前模拟）、订单管理、机器人配送追踪、取餐码取餐、地址/活动。
- **商家端**微信小程序（19 页）：登录、工作台、接单（模拟扫码配单）、一车多单配单/上货、订单与售后、商品管理、配送监控（真实机器人状态）、店铺设置。
- **后端**：Node.js + Express + SQLite，单进程同端口 3000 托管三个服务：
  - 小程序 API：`/api`
  - 管理员网页：`/admin`（首次打开输管理员令牌，默认 `123456`，可 env 覆盖）
  - 数据可视化大屏：`/dashboard`（科技风 + 3D 地图 Map3D）
- **对接**：越凡开放物流平台（真实机器人）真实接口；可切本地 Mock 演示。

远端仓库：`github.com/VesselPaper/lingdong-delivery-miniprogram`

## 5. 登录现状（重点：确保别又改回坏地址）

- 当前**两个小程序**的 `baseUrl` 均为 `http://10.158.178.205:3000/api`（这是本机当前 WLAN IP、浏览器/手机同网可达）。
- **铁律**：改环境/换机器时，务必同步改 `用户端/utils/config.js` 与 `商家端/utils/config.js` 两处的 IP。
  `dev` 用局域网 IP（真机预览），`prod` 用 `localhost`（模拟器）。别把连不上的旧 IP 提交上去（曾因此导致登录失败）。
- 登录走 `POST /api/auth/login`（`backend/domains/user/routes.js`），so client 分 user/merchant 选不同 appid/secret 走微信 code2session。
