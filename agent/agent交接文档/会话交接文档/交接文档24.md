## 四、本会话踩到的坑（都已写进本机项目记忆）

1. **`git commit -- <路径>` 会无视 hunk 级部分暂存**：它把该路径的工作区内容**整份**提交（相当于顺手 `git add` 了它）。本会话拆提交时因此把属于提交③的 hunk 卷进了①。正确做法：先 `git apply --cached`（或 `git add`）把索引摆好，再 `git commit -F <信息文件>`，**不带路径**；提交前用 `git diff --cached --name-only` 断言清单。补救：`git reset -q HEAD -- <该文件>` 把它的索引恢复成 HEAD 再重打补丁。
2. **`.mjs` 是 ESM 作用域，不能用 `require`**：要么写 `import`，要么 `import { createRequire } from 'node:module'` 再引 CJS 模块（本会话第一个重置脚本就是这么失败的）。
3. **`ssh` 发远端命令别用双引号**（PowerShell 5.1 会吃掉内层双引号），**也别让 `<` `>` 裸露**（远端 bash 会当重定向，本会话又踩一次）。远端命令外层单引号、逻辑复杂就写脚本上传再跑。
4. 两个"打开"`.bat` 是 **GBK + `chcp 936` + CRLF**（`.gitattributes` 对 `*.bat` 指定 `eol=crlf`），改它要用 .NET 显式编码写，不能直接 `read`/`edit`。

**UPS 选型结论（2026-10-12 定）**

| 项 | 结论 |
| --- | --- |
| 需求 | 只要"熬过闪断 + 优雅关机"，**不需要**停电后长时间续航 |
| 每台负载 | 满载约 650W（265K 最高 250W + 5070 Ti TGP 300W + 其余约 50W，电源按 90% 效率折算到插座侧）；两台合计约 1350W |
| 方案 | **两台机器各配一台**：在线式（双转换）、纯正弦波、≥1000VA/800W，即山特 C1K 级（参考价约 1300 元/台） |
| 装机商推荐的两款 | **不合格，别要**：山特 TG-BOX 850 = 后备式 850VA/**510W 方波**；TG1000 = 后备式 1000VA/**600W 阶梯波**。功率不到需求一半，且非正弦波，配主动 PFC 电源（振华 LEADEX III）切换瞬间有让电源保护性重启的风险 |
| 关键口径 | **别被"1000VA"字面对等替换**：TG1000 的 1000VA 是 600W 后备式，C1K 的 1000VA 是 800W 在线式，两种东西。看三个指标——在线式/双转换、纯正弦波、**W 数**（不是 VA） |
| 一台带两台为什么不行 | C2K（2000VA/1400W）带 1350W ≈ 96%，同时满载就跳；C3K（3000VA/2100W）功率够但有 16A 插座/单独走线与"UPS 一坏两台全黑"的问题，不如两台各一台 |
| 买的时候要一起问 | ① 带 **RS-232/USB 通讯线 + 山特 WinPower 软件**（没线就只能手动关机，谈不上"优雅关机"）；② 输入侧总功率约 1650W（1350W 负载 + UPS 损耗 10~15%），两台机器 + 两台显示器分插墙面插座/不同回路，别挤一个便宜排插 |
| 同档可换的现货 | 山特 C1K / C1KS（现型号 Castle 1K 6G）、华为 UPS2000-A-1KTTS、科华 YTR1101、APC SRT1000XLI、伊顿 9E1000i |
