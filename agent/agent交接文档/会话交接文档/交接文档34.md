## 二、关键结论（换图/再扩图时直接用）

1. **对齐用"道路掩膜"而不是点位**。14 个取货点做控制点残差 0.8–22m，是系统性分布：
   图书馆/行政楼/舞蹈学院 0.8–3m，东苑一/二/三/十一/十三栋与 A/C 教 14–22m。
   最终用「OSM 道路落在雷达可通行区内的比例」做**有界**精化（尺度 ±6%、旋转 ±4°、平移 ±30m）。
   **不加界会把尺度炸到 396 px/m**。
2. **图书馆→东苑那段是越凡的问题**：重扫时这段本身就画错 15–25m。拟合时这批点不参与，
   否则会把整张图的旋转/尺度带偏。段内目前按 OSM 真值，留待人工微调。
3. **换图必须换默认视角与夸张系数**：`el 22/zoom 0.85`、楼高 0.58、车模 9.0 都是东苑尺度的值，
   全校尺度下校园会压成一条薄带、楼塌成平板。现在三者都按标定跨度自适应。
4. **重构数据必须带地图版本闸**：服务器上旧的东苑逐楼偏移套到新图会把楼搬错几十米。
   已实现 `map_id` 闸（本地/内置/服务器三处都过闸），`verify_keys` 里可见 `addBlds 0→0`。

## 三、踩过的坑（别再犯）

- **`--from-git` 在 Windows 上不能用**：`deploy.mjs --from-git` 会 `git archive` 再解包，
  Windows 自带 `tar` 解中文目录名会坏（`Invalid empty pathname`，目录名变成 `\241\347……`）。
  这次改成「工作区打包 + `--allow-dirty`」，前提是**先确认 `git status --porcelain -- backend 管理员网页 可视化大屏` 为空**。
- **`node --check` 查不出未定义函数**：加自适应函数时把 `function num()` 的旧串一起替换掉，
  语法通过、运行才炸。改完必须真跑探针。
- **`verify_labels.mjs` 的档位写死旧视角**，且默认 `TARGET` 是 3000（被 gitfox 占着）：
  跑它必须显式传 `http://127.0.0.1:3100/dashboard/`。档位已按新默认视角改成 `[[5,0.65],[3,0.53],[2,0.46]]`。
- **Overpass 常 502**：必须带 UA + 4 次退避；龙湖是 multipolygon relation，
  `out geom` 对 relation 返回 0 点，得按 relation id 单独查 outer 成员。
