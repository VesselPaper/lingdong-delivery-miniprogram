## 2. 上线工作结论（本次讨论确定）

### 2.1 服务器（阿里云，企业账号）
- 已决定：**阿里云 ECS 通用型 2核4G，包年约 1000 多元**（月均 85-120 元），地域选**成都**。
- 关键：必须买**通用型 ECS**（可平滑升配），不要轻量应用服务器（升配要重建迁移）。
- 带宽 5M 起步、ESSD 40G 起步；企业账号无学生优惠。
- 参考价：阿里云 99 元活动（经济型 e 实例 2核2G 99元/年）、u1 实例 2核4G 新人价 531元/年——企业账号能否享受需确认。

### 2.2 规模演进规划（重要背景）
- 项目目标：像美团那样，校外外卖 + 多学校（3~10 校，半年~一年内扩张）。
- 三阶段：阶段1 单校 2核4G 够用 → 阶段2 多学校需换 PostgreSQL + 加校区维度 + 升配 4核8G → 阶段3 规模化需 RDS/SLB/OSS/CDN。
- 现在别买大，半年内的钱花在"换数据库 + 数据模型加校区维度"两件代码改造上。

### 2.3 小程序主体
- 现有小程序账号：**企业主体**，计划迁移到**另一个企业主体**（账号迁移 + 公证，1-2 周）。
- 主体迁移期间：**上传代码/体验版/后端部署/联调均可做，不受影响**；正式提审/发布要等迁移完成 + 重新备案（注销旧备案 → 新主体重新备案，2-4 周）。
- 备案数量上限：个人 5 个、个体 5 个、企业 50 个。

### 2.4 阿里云 vs 腾讯云
- 对本项目功能无差别（Node + SQLite + Nginx 全是基础能力）；阿里云文档全、OSS 成熟；腾讯云小程序生态近。
- 已定阿里云，无需更换（备案跟着服务器厂商走，换厂商要重新提交）。
