## 四、本机硬规矩（这一轮新增/强化）

1. 中文文件禁用 shell 读写（老规矩，历史事故：`</b>` 被写坏）。
2. **本机不要写含中文的 `.ps1`**：本机是 PowerShell 5.1，按 GBK 解析 UTF-8 中文注释会整个脚本解析失败。要脚本就写 `.mjs` 用 Node 跑。
3. **通过 `ssh` 发远端命令不要用双引号**（PS 5.1 会把内层双引号吃掉）；外层一律单引号。
4. `.bat` 是 **GBK + `chcp 936` + CRLF**，改它要用 .NET 显式编码写，不能用 `read`/`edit` 直接改。
5. 打包含中文用 Windows 自带 `tar.exe`（pax / UTF-8）→ 统一走 `运维\部署\脚本\build-package.mjs`。
6. **本机不要再起后端**：两端同时连真实平台会重复拉单、重复派车。
7. 仓库默认地址 = 云端（`config.js` 的 `CLOUD_BASE`），本机连本地的改动**不要提交**。
