## 三、关键已核实结论

1. **「开仓的时候就走了」根因**：上货点用 lightTask（5 分钟到期自动返程）+ `keepLoadingSummon` 每 4 分钟发新召唤续命 → 新召唤顶掉旧召唤、车短暂无任务重新决策。**治本 = 上货点改真实配送任务（无倒计时）**，设计 + F1~F6 真机验证清单见 `doc/15`。
2. **越凡 OpenAPI 关键确认**：`DELETE /open-api/v1/lightTask` 存在；`deviceCtrl/close` 关真实任务；`authority/grant+renewal` 控制权是驻停机制；`unloading/confirm` 后车立即返回；**没有修改目的地接口** → 多单配送必须一单一任务（我们自己的 batch.route 决定顺序，不会因改真实任务废掉多单算法）。
3. **路网坐标无桥**：landmarks.pos_x/pos_y 是平台米；map-calibration 楼栋 center 是 OSM 本地米；两者同名楼栋配 10 对做仿射拟合平均残差 2.7km → 不交付假路网，删模块。
4. **GitHub 代理已移除**：global gitconfig 的 `http.proxy=http://127.0.0.1:7890` 是死代理（客户端没跑），已 `--global --unset`；当前直连 GitHub 正常。
