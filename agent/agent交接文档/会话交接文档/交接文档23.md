## 二、怎么做的（可复现的管线）

1. **视觉核验能力先修好**：本会话用的模型 `volces/deepseek-v4-1-flash-260910` 本身支持图片输入，但本机
   `C:\Users\82652\.dsh\profiles\desktop\cordis.patch.yml` 里没给该模型声明 `input: [text, image]`，所以 `read_image` 一直拒绝。
   补上声明后图片可读（本次 34 张全部人工过目过）。**注意：GUI 切换模型可能重写这个文件，声明会丢。**
2. **敲门砖：找到门店的订货平台**。`hnfx1.hndrp.com`（喜琳门配送中心）就是门店的供货平台，商品页自带条码与官方图。
   已爬完它的公开目录（26 个分类 × 分页，234 次请求，**2867 个商品 / 2577 条条码** → `%TEMP%\ld_xlm\index.json`）。
   但门店这 216 个商品里**只有 24 个**在其公开货盘内，且**21 个缺图商品一个都不在里面**（用户选择不登录平台，故到此为止）。
3. **网上找图**：Bing 图片搜索（按「品牌+品名+规格」多组关键词）→ 下载候选 → Windows 内置 OCR 先筛促销字样 →
   再用视觉模型逐张判定 `same/brand_only/type_only/no` + `promo=yes/no`（第一轮 34 商品 × 16 候选 = 544 张，
   第二轮对 20 个难找的商品换正确品牌名定向再搜 145 张）。API 并发 6 会大量 `fetch failed`（限流），降到 3 + 指数退避后 0 失败。
   - 判定 `same` 且 `promo=no` 的才当「真图」；模型判不了的（如品牌读不出）我逐张人工看图定夺。
   - 关键坑：模型会漏掉图上小字横幅（如「日期新鲜」「多种口味 一口爆浆」「量大咨询客服」「49% 高蛋白」），
     所以**最终一定要人眼过一遍拼图**，不能只信模型结论。第一轮自动挑的图里有 9 张就是靠人眼刷掉的。
4. **落图**：统一转成**正方形白底 JPEG（最长边 ≤800，不放大）**，按商品名写进 `backend/seed_images/`，
   同时更新本机库 `image='/store-img/<商品名>.jpg'`（本机服务 PID 2948 无需重启即可见）。
   顺带修好 2 条历史失效路径（`外星人电解质水荔枝海盐950ml`、`汤达人韩式（杯）`：库里写 `.png` 而仓库只有 `.jpg`）。
