## 1. 项目是什么

**校内快递配送机器人**（四川师范大学校内无人送餐/快递车）：
- **用户端**微信小程序（**20 页**）：浏览/加购/下单、微信支付（当前模拟）、订单管理、机器人配送追踪、取餐码取餐、地址/活动/售后。
- **商家端**微信小程序（**22 页**）：账号密码登录、工作台、接单（扫码配单，真实 `wx.scanCode`）、一车多单配单/上货（批次自动定型）、订单与售后、商品/活动管理、配送监控、店铺设置。
- **后端**：Node.js + Express + SQLite，单进程同端口 3000 托管三个服务：
  - 小程序 API：`/api`
  - 管理员网页：`/admin`（账号密码登录）
  - 数据可视化大屏：`/dashboard`（科技风 + 3D 地图 Map3D）
- **对接**：真实 robox 开放物流平台（生产 `robox.eventec.cn`）；`PLATFORM_MOCK=false` 走真实，可切本地 Mock 演示。

远端仓库：`github.com/VesselPaper/lingdong-delivery-miniprogram`
