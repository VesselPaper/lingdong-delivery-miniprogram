### 4.1 那一轮修掉的两个真 bug（别改回去）

- **启动读不到服务器重构数据（根因）**：`loadReconRemote()` 原来一进函数就取接口地址，而地址由**后面才加载**的"大屏骨架共享配置"提供 → 必然拿到空值、直接退出且永不重试。已改为**进入轮询后惰性解析 + 兜底地址**。副作用（原本的设计行为）：**服务器数据优先于浏览器 localStorage**，"改了没点保存就刷新"会被服务器版本覆盖回去。
- **保存防护闸**：手动「保存」在本次会话没做任何改动时**不再写服务器**。因为上面那个 bug 的破坏力是：任何没有本地存档的浏览器（读不到服务器）只要点一次「保存」，就会用内置默认地图（4 栋楼）把服务器版本（5 栋楼）整个盖掉 —— 抢救会话里真的发生过一次，靠用户 Chrome 里还开着的页面 localStorage 才救回第 5 栋楼。

### 4.2 一次编码事故（已修复、未提交，但必须记住）

抢救会话用 `Get-Content -Raw | Set-Content -Encoding utf8` 改 `index.html` 的版本号 —— PowerShell 按 **GBK** 解码 UTF-8 文件，中文全变乱码，且转换时**吃掉了 `<` 字符**：`—</b>` 变成 `鈥?/b>`，`</b>` 失效 → `<b id="kvShop">` 永不闭合，**把地图卡片和右栏一起吞进左栏**，地图高度塌成 0。已从 HEAD 恢复，并改用 Node 按字节重做版本号。规则已写进 `AGENTS.md`（见 §6）。

- 仓库根**不是**会话工作目录：代码在 `D:\...\校内快递配送机器人\` 下。临时脚本放 `_tmp4\probes\`（UTF-8）。

- **DSH 会话归档是多帧 zstd 拼接**的 `session.v4.jsonl.zstd`，`zstdDecompressSync` 直接读只会得到第一帧（一行）。用 `_tmp4\probes\session\sess.mjs` 系列查看历史会话。
