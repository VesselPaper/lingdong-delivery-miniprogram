## 3. 正在进行 / 未完成的事（★当前主线）

### ★★ 雷达图"左边缺一块（正方形）"BUG —— 当前焦点

**用户描述**：雷达图上左边/某处有一块缺失的空白，一直存在、与状态无关；其余渲染正常；**缺口形状应该是正方形**。

**已做的排查与结论（重要，别推翻重做）**：
- 雷达图底图 = `可视化大屏\assets\radar-ground-dark.png`（1800×1682，RGBA）。
- 底图在 WebGL 里由地面 quad（`scene3d.js` 里 `ground`，pos 覆盖 `[0,0]→(radarW,radarH)`，UV 0..1 铺满）贴图，用 `FS_GROUND` 按亮度抠背景。radarW/radarH 来自 `calib.radar_full_size`（fallback 5786×5406），`pxPerM` 来自 `calib.scale_px_per_m`（fallback 19.45）。
- `FS_GROUND`（shaders.js）：`lum=max(r,g,b)`；`a=smoothstep(uFade, uFade+uFadeSoft, lum)*uOpacity`；另有边缘羽化 `smoothstep(0.0,0.012,e)`。参数在 map3d-gl.js：`GROUND_FADE=0.165, GROUND_FADE_SOFT=0.10, GROUND_OPACITY=0.95`。
- **用 Node 解析底图像素**得出的结果：底图内容集中在**左右两条竖直带**（各一排楼/块状物），中间是大片空场——即"两排楼 + 中间空地"布局正常。左边 band0 有约 10 万+ 亮像素，**底图左侧不是空的**。
- 用 headless Edge + CDP 真实截图（`_tmp3/capture_map.mjs`，已开 `#m3Ground` 雷达图层）并像素分析：左半 dark≈28%、右半 dark≈33%，各纵向 band 亮像素≈5 万，**没有明显不对称空洞**。
- **结论**：底层贴图本身左侧有内容，真实渲染帧也没有左右不对称大洞。因此该"正方形缺失"**更可能来自其它层**，而非底图贴图本身。候选方向见下。

**待你接手的方向（按可能性）**：
1. **相机取景/朝向**：默认俯仰角/方位角（`view.az`,`view.el`,`fitCamera` 的 margin/target）把场景左侧裁出视口，或某栋高于画面导致遮挡。查 `S.fitCamera` / `makeCamera` 参数。
2. **覆盖层遮挡**：某楼体边缘、OSM 灰色层、`rownHalo/roofs/glass`、或叠加 canvas(`#mapBox` 里 z-index 1/2 的两个 canvas)某块遮住了雷达图。查 `map3d-gl.js` 各 mesh 与玻璃绘制顺序。
3. **地面 quad 的 UV / flip**：确认纹理翻转（`UNPACK_FLIP_Y_WEBGL false`）与地面朝向是否让内容错位隐藏。
4. **Leaflet / Dash.map 的 2D 覆盖叠加在 WebGL 之上**。
5. 建议再写一个更细的 CDP 截图探针：只对 `map3d-gl` 的 WebGL canvas 单独导出像素统计，分区块（比如 4 行 × 6 列）打印平均亮度，精确定位方块空洞坐标 → 再逆推是哪个 mesh/范围。
