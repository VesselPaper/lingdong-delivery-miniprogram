## 二、遇到的问题 / 踩的坑

1. **跑道第一版是"一整片红"**：OSM 的 `leisure=track` 多边形是跑道**外轮廓**（含内场），
   先 `fillPoly` 铺满再叠分道带，远景就是一块红。改成只画分道带、内场留空，下面的操场草皮自然透出来。
2. **覆盖度一开始全是 0**：雷达与 OSM 有 5–20m 对齐残差，膨胀半径只有 1.8m 时中位数直接是 0。
   放大到 0.8 m/px、膨胀 20m 后变成合理双峰（p75 全命中）。
3. **标注探针的口径过期**：`verify_labels.mjs` 原断言"被遮挡必须整条隐藏、不许半透明"，
   这次正好反过来。已改成"不许出现 alpha=0，且必须出现半透明条目"。
4. **平台地图接口偶发失败**：这次跑 `verify_labels` 时云端 `overview` 的 `map` 为 null
   （`未同步点位或获取地图失败`），点位名一条都没有 → 3 条站点相关断言失败。
   **这是上游数据缺失，不是代码问题**，楼名相关断言全部通过、0 console 报错。
