## 一、需求

> 因为移动俯仰角导致的重叠，就用物理效果重叠就行了，不要消失。

## 二、改了什么

上一版在排版收尾有一道「最终落位校验」：按优先级逐个收，**撞上已落位的框就丢弃后者**。
本意是实现"梯度内零重叠"，但副作用是：

- 有些楼名从一开始就被丢掉，永远不出现；
- 俯仰角一变，同样两条文字又会撞上 → 再消失一次，读起来像闪烁。

按要求删掉这道丢弃逻辑，改成**只排序不丢弃**：

```js
// 按体量从小到大排，大的后画、压在上面
placed.sort(function (a, b5) {
  var pa = (a.members.length || 1) * 1e6 + ((a.lead && a.lead.area) || 0)
  var pb = (b5.members.length || 1) * 1e6 + ((b5.lead && b5.lead.area) || 0)
  return pa - pb
})
```

重叠时小的先画、大的压在上面，形成自然的遮挡关系。配合上一轮的「布局冻结」
（俯仰角 `el` 不在 layoutKey 里，改俯仰不触发重排），最终效果是：
**改俯仰角只是让文字互相压住，不会让任何一条文字消失。**
