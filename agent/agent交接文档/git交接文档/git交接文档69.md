# git 交接文档 69 —— 名称清洗：去掉「川师」前缀，餐厅改为「龙湖餐厅」

日期：2026-11-19
上一份：`git交接文档68.md`（美术第一轮，提交 `c734efe`）

---

## 一、需求

负责人要求：`川师龙湖餐厅、云海餐厅` 改成 `龙湖餐厅`；其他标在地图上的名字，**凡带「川师」都去掉这两个字**。

## 二、做法

**1. 统一清洗，而不是逐条改名**

在 `emit_assets.mjs` 输出前加一道 `stripSchoolPrefix`，对楼栋、场地、水体的名称统一执行
`String(name).replace(/川师/g, '').trim()`。

为什么放在生成阶段而不是补丁文件里逐条改：OSM 数据以后更新时，「川师」会被重新带回来，
放在生成阶段才能一劳永逸。补丁文件里的 `rename` 仍然保留，用来处理「名字本身就不对」的情况。

**2. 餐厅单独改名**

`川师龙湖餐厅、云海餐厅` 去掉「川师」后是 `龙湖餐厅、云海餐厅`，仍有「、云海」两个多余的字，
所以在 `assets/map-fields-extra.json` 的 `rename` 里按 `osm_id` 指定：

```json
"934177932": "龙湖餐厅"
```
