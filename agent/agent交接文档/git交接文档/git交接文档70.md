## 一、负责人要求

1. 文字标注的消失范围不统一，要先分层：**一个梯度就一类大小**，不同梯度不同时显示；
2. 点位要在某个梯度里显示；
3. 某个梯度里若看到文字重叠，要么这个梯度太细、要么字太大，要处理掉；
4. 密集处可以把**一坨地方合并成一个标注**（这一片的名字），放大到下一梯度再整齐细分；
5. 默认镜头拉近一点，让整个校园刚刚好在地图框里；默认这一档要显示**具体楼栋**，
   如果太密，**优先缩小字体**。

## 二、旧实现为什么"消失范围不统一"

同一个楼名同时受四套互相独立的规则控制：

| 规则 | 阈值 |
| --- | --- |
| `showT1` 缩放区间 | zoom ∈ (0.50, 1.25) |
| `allowedPr` 分级 | zoom ≥ 0.78 只留 1 级楼名 |
| `cap` 数量上限 | 0.90 / 0.78 分档，14 / 22 / 40 条 |
| 深度淡出 + 屏幕边缘淡出 + 重叠降透明 | 连续变化 |

四套阈值互不相同，所以"这栋为什么没了、那栋为什么还在"无法解释。字号还是 `11 / zoom` 连续变化的，同一梯度里字号一直在变。

## 三、新实现

### 1. 五个梯度，同一时刻只出一个

数组按 `minZoom` 从大到小排，取第一个满足 `z >= minZoom` 的档：

| 梯度 | zoom 区间 | 内容 | 字号 |
| --- | --- | --- | --- |
| L0 片区 | ≥ 1.45（最远） | 东苑宿舍区 / 西苑宿舍区 / 教学区 / 运动区 / 生活服务区 | 14 |
| L1 地标 | 1.05–1.45 | 非宿舍类主要楼栋 | 12（密集降到 9） |
| L2 全部 | 0.75–1.05 | 全部楼栋 | 11（降到 8） |
| L3 细分 | 0.55–0.75 | 全部楼栋（**默认视角在这里**） | 12（降到 8） |
| L4 点位 | < 0.55（最近） | 取货 / 上货 / 充电点名称 | 11 |

**注意 zoom 的语义**：这里 zoom 越小画面越大（越近）。第一版按"zoom 越大越近"写，梯度整个反了 ——
在最近处显示片区名、在最远处显示点位名，已修正并用 5 个档位截图逐一核对。

### 2. 梯度内零重叠：先缩字号，再合并

- 按重要度（面积 × 送餐楼系数 2.2）从大到小落位，大块先占位；
- 每条文字算出屏幕包围盒，与已落位的框相交就并入那一簇；
- **字号阶梯**：从该档最大字号开始试，每降 1px 重排一次，直到"零合并"；
  降到最小字号仍然重叠才保留合并（默认档实测 12→8 后只剩 1 处合并）；
- 合并簇的文案：成员里有 ≥ 半数属于同一片区 → 直接写片区名；否则写"最大那个等 N 处"；
- 同名片区再归并一次（否则会出现 4 个「东苑宿舍区」），锚点移到该片区成员的面积加权中心；
- 最后再做一遍落位校验，保证梯度内**任意两条文字都不重叠**。

### 3. 去掉了三套连续调制

深度淡出、屏幕边缘淡出、重叠降透明全部移除 —— 它们正是"同一个类别的字亮度、消失时机各不相同"的来源。
现在梯度内一律 `alpha = 1`、同一字号。

### 4. 默认镜头

`resetView` 不再写死 zoom，改为按画布实测取景：

1. 把建筑 / 场地 / 水体的**所有顶点**投影到屏幕，取实际屏幕包络
   （不用世界坐标 bbox 的四个角 —— 对角线角上通常是空白，会明显偏保守；
   实测角点已占 93% 画布宽，画面里校园却只占一半）；
2. 按"包络占画布 94%"反推 zoom。投影偏移与 zoom 成反比，所以是**除**不是乘
   （第一版写成乘，默认视角反而缩得更远）；
3. 结果：默认 zoom 0.92 → 0.711，校园正好铺满画布。
