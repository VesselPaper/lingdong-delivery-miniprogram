## 二、为什么这么改

负责人反馈：无人车都在「商铺上货旁那栋（三个连着的建筑、中间是办公室）」充电，**多车在充电点堆积时地图上糊成一团**。且虚拟车静止态（充电/等待/上货/待取货）都停在代表点位（`virtualRobot.js:21`）→ 位置完全重叠。

## 三、遇到的问题 / 踩的坑

1. **3D 车循环与叠加层都要用聚类结果** → 每帧在 `render()` 里算一次、存模块变量 `_carClu`，两处共用（不在两处各算一遍，避免不一致）。
2. **簇「代表」优先选选中车**，保证选中车的数据牌/金色高亮不丢。
3. **用屏幕距离聚类（而非世界距离）** → 放大后点位分开会自动拆簇（LOD）：默认视角显示「N台」徽标不糊，放大到库房细节时逐台显示。
4. **验证需要"多车同点"**：临时开虚拟车（`POST /api/dashboard/virtual-robot {enable:true}`）制造充电堆积，验证完**关回**。
5. **并发提交冲突**：写本份时发现 19 号已被另一个 agent 占用（`eedbeec`，后端清告警），改用 20 号；他的提交只动后端 delivery，与大屏无重叠。
