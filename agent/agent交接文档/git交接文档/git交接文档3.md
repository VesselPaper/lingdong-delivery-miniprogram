## 3. 遇到的问题 / 踩到的坑

1. **工作区根与仓库根各有一个「可视化大屏」目录，一度疑似代码分叉。**
   实测结论：**不是分叉**。工作区根的 `可视化大屏\` 里只有一个文档 `doc\可视化大屏采购调研.md`（7245 字节），**没有任何代码**；真正的代码只在仓库内 `校内快递配送机器人\可视化大屏\`（39 个文件，`index.html` 17668 字节）。该目录名容易误导（`git` 里也只有仓库内那份被跟踪），建议后续改名为「大屏采购调研」之类的纯文档目录名。
2. **`backend/data/admin-calib.json` 在本机不存在。**
   `交接文档17` §4.3 把它列为"上线必搬文件"，但本机实测不存在；`backend/services/platform-http.js` 第 541 行只是定义了 `CALIB_FILE` 路径。`AGENTS.md` §6 暂按文档表述为"不进仓库（定位标定）"，**该表述待负责人确认后再改**，否则会误导下一个 agent。
3. **两份 `AGENTS.md` 内容重叠。**
   工作区根那份（负责人私有记忆，含 `_tmp4` 探针、大屏机采购与装机要求、上线节点）与仓库根这份（工程规范）都会被执行 AI 读取。已确认的分工：**工程规范类内容只留在仓库版**，工作区版保留负责人私有信息，后续按此去重。
4. **中文文件读写一律绕开 shell。**
   本次新增的 `AGENTS.md`、本文件全部用编辑器/字节安全方式写入；行数与乱码用 Node 按字节复核（见 §4），未使用 `Get-Content` / `Set-Content` / `>`。
