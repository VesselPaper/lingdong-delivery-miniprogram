## 一、发现的问题

上一轮加了"跨梯度 200ms 交叉淡化"之后，出现一个新的抖动源：
**梯度分界没有滞回**。

`labelTierFor` 原本是纯阈值判断（`z >= minZoom` 就取该档）。用户在分界附近轻微缩放
（比如在 0.75 上下晃），就会反复跨过阈值 → 反复换档 → 每次都触发一次交叉淡化 →
看起来是"文字一明一暗地抖"，比不加过渡还糟。

## 二、做法

给梯度选择加 **4% 滞回**：

- 想往**更远**的档走（zoom 变大）：必须超过当前档下限的 104%；
- 想往**更近**的档走（zoom 变小）：必须低于当前档下限的 96%；
- 落在滞回带内时保持当前档不变。

```js
var HYST = 0.04
var curMin = LABEL_TIERS[labelTierId].minZoom
if (want < labelTierId) {           // 去更远的档
  if (z < curMin * (1 + HYST)) return LABEL_TIERS[labelTierId]
} else {                            // 去更近的档
  if (z > curMin * (1 - HYST)) return LABEL_TIERS[labelTierId]
}
```
