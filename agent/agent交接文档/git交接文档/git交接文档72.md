# git 交接文档 72 —— 标注跨梯度切换加 200ms 交叉淡化

日期：2026-11-19
上一份：`git交接文档71.md`（物理重叠，提交 `1c2993b`）

---

## 一、背景

上一版把标注按梯度分层后，跨梯度是**整批瞬间替换**：从默认档拉远一档，38 条楼名"啪"一下全部变成
12 条地标名，视觉上很硬。负责人同意加过渡。

## 二、做法

在标注绘制阶段加一层交叉淡化：

1. 每帧结束后，把这一帧**真正画出来的那套**（文字 + 颜色 + 世界坐标锚点）记到 `labelDrawn`；
2. 检测到梯度 id 变化时，把 `labelDrawn` 复制为 `labelFade.from`，记录起始时间；
3. 过渡的 200ms 内：
   - 旧的一套按世界锚点重新投影，用 `sqrt(1-k)` 的透明度画（淡出）；
   - 新的一套用 `sqrt(k)` 画（淡入）；
   - `k = (now - t0) / 200`，`k ≥ 1` 时结束过渡；
4. 两套都按世界坐标锚点重新投影，所以过渡期间它们跟着相机走，不会脱位。

**为什么用 sqrt 而不是线性**：线性的中间帧两套各 50%，叠在深色底上会明显发灰，
看起来像文字"闪一下变暗"。开方后中段各约 71%，交叉淡化更顺。

## 三、几个实现细节

- `_lastLabels`（探针与调试读的那份）始终报告**新的一套**、`alpha = 1`，
  不受过渡影响 —— 否则探针在过渡中采样会误判"标注被淡出"。
- 过渡只影响绘制时的 `globalAlpha`，改完立刻复位为 1，不影响后续车辆标签。
- 梯度内**不**做任何淡化：同一档里始终 alpha=1，这是上一轮的既定规则。
