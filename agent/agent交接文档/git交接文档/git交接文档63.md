## 一、为什么还要补这一笔

负责人指出：体育场看台旁边还有两块操场，它们也应该有红色跑道。

查标定数据确认这个判断是对的：

| 场地 | 面积 | OSM 里的类型 | 上一版画出来的样子 |
| --- | --- | --- | --- |
| 川师第一运动场 | 7261 m² | `pitch` | 纯绿（旁边另有一个真实的 `leisure=track` 环，11507 m²） |
| 川师第二运动场 | 6957 m² | `pitch` | **纯绿**（OSM 没标跑道环） |
| 一号运动场 | 7654 m² | `pitch` | **纯绿**（OSM 没标跑道环） |
| 篮球场 / 网球场 / 风雨球场 | 2152–5968 m² | `pitch` | 纯绿（本来就不该有跑道） |

问题根源：OSM 里这三块大操场只画了草皮面，只有第一运动场额外标了 `leisure=track`。
所以第二运动场、一号运动场画出来就是一块纯绿。

## 二、怎么补的

**规则放在标定生成阶段**（`emit_assets.mjs`），渲染层只认标记：

1. 面积 ≥ 6000 m² 的 `pitch` 才考虑；
2. 且附近（半径 1.2 倍）**没有**真实的 `track` 面，才允许合成；
3. 命中就写 `track: true`。

结果：`川师第二运动场`、`一号运动场` 拿到 `track: true`；
`川师第一运动场` 因为有真实跑道环而保持不变；小球场按面积被排除。

**渲染**（`scene3d.js` 的操场分支）：带 `track` 的操场按「外圈跑道 + 内场草坪」画：

- 整个多边形先铺跑道底色（深砖红）；
- 沿轮廓内缩 4 条白色分道线（宽度按场地的 16% 推算，夹在 6–10 m，约等于标准 8 道）；
- 草坪按一个跑道宽度内缩后盖上去，剪草条纹/中线/中圈都按内缩后的草坪边界画；
- 最外圈描一道白边线。

这样跑道环完全落在原有多边形内，不会溢出到相邻道路上。
