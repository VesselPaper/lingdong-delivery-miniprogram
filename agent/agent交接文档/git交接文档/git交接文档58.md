## 三、遇到的问题 / 踩的坑

1. **「不做实测」不等于「没有依据」。** 一开始担心砍掉自测会让结论变软，实际反而更硬：需求本来就是从校园几何反推的（§5），自测只能证明"旧车多差"，证明不了"新车能不能达标"。真正能约束供应商的是**第三方报告 + 合同口径**，而不是我们蹲点。
2. **`web_search` 批量查询会挂。** 一次传 4 条 query 报 `TypeError: object is not iterable`（DeepSeek 搜索端点返回体异常），改成一次 1–2 条就正常。**以后批量检索按 2 条一组发。**
3. **政府/标准文件多为 PDF，`web_fetch` 不支持（`unsupported content type "application/pdf"`）。** 只能退到 HTML 版政策页（北京市政府门户那条能读全文），或找第三方解读页（GB/T 20721 用的是 antpedia 解读，已在文中标注"二手解读，非原文"）。
4. **国标 ±10 mm 不能直接搬到室外。** GB/T 20721-2022 是仓储 AGV（有反光板/固定路径），照抄会得出"±1 cm 才合格"的错误结论。文中明确写了"室内、有反光板，与校园室外不是一类"，避免叶总拿错标尺去压价。
