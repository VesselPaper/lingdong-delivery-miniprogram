## 三、道路：OSM 里根本没有，从雷达可通行区抽出来

先核实："路在不在库里" —— **在**，西苑一带 OSM 的 6 条 `service` 全部进了标定，
且雷达覆盖度 0.85–1.0（渲染是全亮）。问题是**它们全挤在西苑东侧**，
两排宿舍之间 OSM 一条路都没画。

负责人指出雷达图里有这条路。于是新写 `extract_corridor.py`：

1. 给一条**粗引导线**（2/4/5 与 3/6/7 两排宿舍对应楼的中点连线）；
2. 沿线每 2m 取一站，在垂直方向 ±15m 内扫可通行区，取连续段的中心；
3. **加连续性约束**（选最接近上一站的那段、单步限 3m）—— 第一版没约束，
   法向扫到不同通道，路径来回折返，长度算出来 1567m（实际只有 160m）；
4. 滑动平均平滑 + Douglas-Peucker 简化（容差 1.5m）。

结果：**172m、10 个点**，从 (2638,6963) 到 (43,8992)，正落在两排宿舍中间。

## 四、补丁机制扩展

`assets/map-fields-extra.json` 现在是统一的补丁入口，四类改动都不用动代码：

| 键 | 作用 |
| --- | --- |
| `rename` | 按 `osm_id` 改楼名（本轮新增） |
| `roads` | 新增 OSM 没有的道路，`pts` 用雷达像素（本轮新增） |
| `reclassify` | 按 `osm_id` 改判运动项目 |
| `fields` | 新增 OSM 没有的场地 |
