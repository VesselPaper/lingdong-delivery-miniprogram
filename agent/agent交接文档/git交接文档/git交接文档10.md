## 三、遇到的问题 / 踩的坑

1. **`.docx` 不能直接 grep**（zip 二进制）。做法：用 `System.IO.Compression` 打开，读 `word/document.xml`，正则去标签后按文本扫。
2. 打印命中行时**先打码**再输出（`secret/appid/key/password/token` 后面的值、以及 24 位以上长串一律替换成占位符），避免把凭据打进对话记录。
3. 这 6 份交接文档是"历史记录"，本次**只补交、不改内容**；要改现状请写新的《交接文档N》，不要回头改旧的（否则历史失真）。
