## 二、为什么这么改

负责人反馈「商铺上货这一片，有很多点位很近」。实测这一片挤了 3 个点：
- **商铺上货** (loadingPoint, 17.168,-3.435)
- **零栋库房** (deliverPoint, 14.05,-3.317) ≈ **3.1m**
- **充电点** (chargePoint, 17.328,0.814) ≈ **4.3m**

默认视角下几乎叠成一个点。按优先级隐藏低优先级的点位+名称，只留最高优先级的「商铺上货」。

## 三、遇到的问题 / 踩的坑

1. **阈值 `SITE_CULL_PX=36`**：默认视角该片只剩「商铺上货」；放大到 zoom≈0.47 时充电点/库房**仍被裁**（实测放大后它们与商铺上货的屏幕距离仍 <36px）。如需"放大到库房细节时充电点重现"，把阈值调小（如 24），一处改动。
2. 优先级判定写在 `drawOverlay` 内（`isLoad`/`isCharge`），要改排序只动一处。
3. `verify_labels.mjs`（在 `_tmp4`，**不进仓库**）已加新断言：商铺上货必须始终保留、打印各缩放档站点名清单。
