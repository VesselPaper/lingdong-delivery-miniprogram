## 二、为什么改

`ca0c5d5` 部署后实测：两台虚拟车停在同一点（屏幕 (38,495)），却各自成 `size=1` 的簇、合不拢。根因就是簇质心初始为 `(0,0)`、比较前没更新。

## 三、遇到的问题 / 踩的坑

"边比较边累积"的聚类，累积值（质心）必须在比较前保持最新；用占位初值参与比较会让所有第二台车都比到原点去。
