## 二、为什么改

负责人要求：**商铺上货等点位被遮挡时，不要显示名称，只留图标标记**。原来"重叠只降透明度"会显示半透明残影，改为被遮挡就整条隐藏（图标是独立绘制的，不受影响；不遮挡时名称正常显示）。

## 三、遇到的问题 / 踩的坑

1. `_lastLabels` 快照保留 alpha=0 条目 → 探针可断言"确实隐藏了"（否则无法验证）。
2. 旧断言"商铺上货 点位名始终保留"不再成立（被遮挡时隐藏）→ 改为"放大后不遮挡时出现"。
3. 楼栋名优先级不变（先占位、从不被点位名挤掉）—— 本次只动点位名。
