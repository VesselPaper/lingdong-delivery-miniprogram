## 三、遇到的问题 / 踩的坑

1. **`git diff --output=<file>` 没生效**：把 `--output=` 放在 `--` 之后被当成了路径参数，补丁文件没生成、diff 打到了终端。绕开：既然这些文件本地没改过，直接用 `git checkout origin/main -- <文件>` 拿整文件，最简单也最安全。
2. **成员提交是"券+文案+购物车"三合一**，不能整提交 cherry-pick，必须文件级挑选；已用 grep 对 14 个文件复核无"优惠券/coupon/receiveCoupon/cart-panel"等残留。
3. **区分"旧的促销 UI"与"新券功能"**：本地基线（72cb732）的 `order/confirm`、`index` 本来就带 `coupon-*` 命名（促销卡片/优惠选择面板），这些**不是**成员新增的券功能，也不在本次同步范围，别误判。
