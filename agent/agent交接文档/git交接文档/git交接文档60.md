## 三、遇到的问题 / 踩的坑

1. **「重写」不等于「换个顺序」。** 第一版重写时我只是把 04 的章节按结论前置，结果还是带着"§2.1 / §9.1 / 与已有文档的关系"这类内部痕迹。真正有效的是**先定读者会问的五个问题**（哪个参数、为什么大图更差、为什么 2.2≠12、提多少、怎么验收），再让每一节只回答一个。
2. **第一版写成了"作者旁白"。** 首稿 275 行，塞了提交对象/编制/「本文回答三个问题」的开场引述、A/B/C/D 四级证据表、自我披露段落、「本文没回答的问题」，正文里还有"这张表是全文最重要的一张""这条数据的意义"这类话。负责人指出「不要有多余的注释和解释」后重写为 200 行：只留结论、数据、参数，证据等级挪回内部底稿 `04`。**教给别人的文档，不解释"我是怎么想到的"，只给结论和依据。**
3. **反复撞到"一句话"这个雷。** 项目 AGENTS 明确禁止用"一句话"当小标题或行内标签（2026-10-23 定），这一轮又在 05 和 06 里各犯一次，已改为"概括为一句""解释""总结"。**写文档时要主动 grep 一下"一句话"。**
