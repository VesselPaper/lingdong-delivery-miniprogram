## 二、为什么改

负责人反馈"点位的字体统一一下，11栋和7栋感觉和其他的字不一样"。排查（`probe_label_dump.mjs`）：所有东苑名都是粗体 12px，**差异是亮度** —— 距离淡出让近的 11栋/13栋 alpha≈1.0、远的 1栋 0.45。统一后所有标注同亮度、点位名同字号。

## 三、遇到的问题 / 踩的坑

1. 根因不是字体而是**距离透明度**，先探针打印各标签 kind/alpha 才定位到。
2. 缓存键：`3d90` 曾被 3D 针版本用过，复用会让缓存过旧浏览器拿到 3D 针代码 → 用全新 `3d91`。
3. 顺带发现：上一笔 `224507a`（车标记贴地椭圆）**忘了 bump 版本号** → 本次 bump 一并解决，墙机浏览器会重新拉取（含上一笔修复）。
