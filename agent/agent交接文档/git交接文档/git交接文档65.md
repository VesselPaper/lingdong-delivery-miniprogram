## 一、本轮两件事

### 1. 楼高默认降一半

负责人反馈「楼的高度默认太高了，降成一半就行」。

| 位置 | 原值 | 新值 |
| --- | --- | --- |
| `opts.heightScale` 默认 | 1.7 | **0.85** |
| 自适应公式基准 | `0.58 × 跨度/6200`，夹 0.5–2.6 | `0.29 × 跨度/6200`，夹 0.25–1.3 |
| 工具栏「高度」滑块 | min 20 / max 260 / 默认 170 | min 20 / max **160** / 默认 **85** |

全校跨度约 19600 px，自适应结果从 **1.83 → 0.92**，正好一半。

### 2. 篮球场 / 网球场单独建模

之前这些场地被归成 `pitch`（草地），画出来就是一片绿 —— 原因有两个：

- **分类错**：那几个有名字的「篮球场 / 网球场 / 风雨球场」在 OSM 里既没有 `sport` 标签、
  也没有 `landuse`，落到了默认分支 `kind = 'pitch'`；
- **没有模型**：即便分类对了，`court` 分支也只是"平涂色块 + 外框 + 一条中线"。

改法是两步：

**① 分类按名字兜底**（`emit_assets.mjs`）：`/篮球|网球|羽毛|排球|球场/` 命中即判 `court`。
另外把运动项目归一成 `basketball / tennis / badminton / volleyball`，优先看 `sport` 标签，
没有标签再看中文名。

**② 按标准尺寸平铺 + 划线**（`scene3d.js` 的 `drawCourtMarks`）。关键认识：
这些多边形是**一片场地**而不是一块球场 ——

| 场地 | 多边形尺寸 | 可排 |
| --- | --- | --- |
| 篮球场（东苑） | 92×37 m | 3×2 = 6 块 |
| 篮球场（另一片） | 97×42 m | 3×2 = 6 块 |
| 网球场 | 83×74 m | 3×5 = 15 块 |
| 风雨球场 | 77×28 m | 通用（只画外框 + 中线，不臆造） |

所以做法是：整片铺基层沥青色 → 按标准尺寸平铺若干块球场 → 每块画自己的白线。

划线按真实规则：
- **篮球**（28×15 m）：边线、中圈 1.8 m、禁区 5.8×4.9 m、罚球圈、三分弧 6.75 m、篮圈；
- **网球**（23.77×10.97 m）：边线、单打线 4.115 m、发球线 6.4 m、中央发球线、球网（加粗）；
- **羽毛球**（13.4×6.1 m）：边线、中线、前发球线 1.98 m、双打后发球线 5.94 m；
- **排球**（18×9 m）：边线、中线、进攻线 3 m。

配色：篮球场地砖红、网球场青绿、羽毛球场墨绿、基层深沥青色、白线统一浅白。
