## 二、为什么改

负责人反馈「小车名称文字和楼栋文字一样，要区分」。原来小车名（淡青发光）与楼栋名（淡青粗体）撞色，地图上分不清哪个是车、哪个是楼。改后：**车 = 白字 + 圆点**，**楼 = 淡青字**，一眼可分。
