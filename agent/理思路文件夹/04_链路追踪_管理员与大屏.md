# 04 · 链路追踪 · 管理员网页 & 数据可视化大屏

> 管理员网页：`管理员网页/index.html` + `admin.js`（Swiss 风格，无框架，IIFE + window.* 全局函数）。
> 大屏：`可视化大屏/`（只读聚合页）。后端都是同一进程 3000 端口：`/admin` 与 `/dashboard/`。

## 0. 公共请求层（管理员）

- `admin.js:33 api(path, method, body)` → `fetch('/api/admin'+path, {headers:{'x-admin-token': token}, …})`
- token 存 localStorage（TOKEN_KEY='lingdong_admin_token'）；401 → 显示登录横幅
- 页面路由：window.navTo（navTo 必须挂 window，HTML onclick 全局调用）
- 刷新：`refresh()` → `api('/state')` → render()；雷达 `pollRadar()` 3s 轮询

## 1. 页面加载 → 状态总览

- **前端**：init() → `api('/state')`（admin.js:510）
- **后端**：`server.js:2305 GET /api/admin/state`（adminGuard）
  1. `platform.getDeviceList` → out.robot（第一台车）
  2. `platform.listPlatformTasks` → out.platform_tasks（平台侧全量任务）
  3. 本地 SQL：delivery_batches（活跃 LIMIT 50 + 终态 LIMIT 100）、orders（活跃+终态）、delivery_tasks（void_at IS NULL AND <80 + 其余）
  4. 死锁检测 alerts：
     - 本地任务卡中间态（20/30/40/50/60/70/71）超 ADMIN_STUCK_MIN(10min)
     - 本地任务异常态（90/100/120）
     - 平台任务异常态（90/100/120）
     - 机器人 exception / 离线
- **表**：delivery_batches、orders、delivery_tasks（读）；平台数据

## 2. 实时雷达（总览页 col-6）

- **前端**：`pollRadar()` → `api('/radar?device_sn='+sn)`（admin.js:490）→ `drawRadar(data)`
- **后端**：`server.js:2356 GET /api/admin/radar` → `platform.getRobotRadar(store, sn)`（platform.js:1039）：
  - iotGatewayProxy/{sn}/buildingManager/om-api/EvizServer 代理，3s 缓存
  - 返回 {ok, timestamp, locQuality, robotPose, laserscan, costmap(点云/代价地图)}
  - 机器人离线 → 平台网关 Read timed out（COMM_500）→ 前端占位「机器人离线，无雷达数据」
- **表**：无（纯平台数据）

## 5. 一键初始化（危险操作，设置页）★核心

- **按钮**：「一键初始化」→ `$('reset').onclick`（admin.js:603）→ 多行 confirm（提示会关闭任务/取消订单/清理批次）→ `api('/reset','POST',{})`
- **后端**：`server.js:2467 POST /api/admin/reset`：
  1. 关闭平台活跃任务：本地库 `delivery_tasks`（device_sn 与 platform_task_id 非空、未 void、非终态）全部 `platform.closeTask`
  2. 释放控制权：`delivery_batches.ctrl_id≠''` 全部 `platform.releaseControl` → 清 ctrl_id
  3. 取消活跃订单：orders status IN (0,1,2,3,6) 逐单 `applyOrderCancelled(reason='管理员一键初始化')`（本地取消+平台召回）
  4. 批次置 4：delivery_batches status IN (0,1,2) 全部 → 4「测试清理已取消」+ 清 device_sn
  5. 审计 audit_logs（action='admin/reset'）
- **表**：delivery_tasks、delivery_batches、orders、audit_logs（全写）；平台（closeTask/releaseControl）

## 7. 数据可视化大屏（/dashboard + /api/dashboard/*）

- 页面：`可视化大屏/index.html`（Leaflet + 高德瓦片渲染），5s 轮询 `fetch('/api/dashboard/overview')`
- **后端**：`server.js:1752 GET /api/dashboard/overview`（免登录）：
  - 5s 缓存（dashCache）
  - map：`platform.getMapOverview`（底图/路网/点位/机器人/路线，失败降级 null）
  - robots：`platform.getDeviceList`（在线/电量/状态）
  - batches：delivery_batches status 0/1/2 + 子查询 orders（active_orders/waiting_pickup）
  - pickup_alerts：orders status=3 未取且 pickup_timeout_stage>0（大屏红色提醒）
  - stats：computeStats()、shop：shopWithRuntime()
- `server.js:1732 GET /api/dashboard/map-image`：平台位图代理（10min 缓存）
- **表**：delivery_batches、orders（读）；平台数据
