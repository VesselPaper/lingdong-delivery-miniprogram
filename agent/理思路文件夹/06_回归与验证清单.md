## 2. 真机/人工回归流程（每步必做）

### 2.1 环境前提

- 机器人上线：`R110A2603AUEQC00` 在线（平台设备列表确认）
- 双端 IP：10.75.178.169:3000（换网络必改 config.js）
- 管理员令牌：123456

### 2.2 用户端流程
1. 登录 → 首页/商品/购物车/地址可用
2. 下单（选点位+收餐人+手机号）→ 模拟支付 → 订单待接单
3. 超过 12 件自动拆单 → 显示多个订单
4. 订单列表/详情/红点正确
5. 免费窗口内取消 → 订单 5 已取消；超窗口提交取消申请
6. 售后：退款/投诉申请

### 2.3 商家端流程
1. 登录 → 首页统计正确
2. 接单（手动 + 自动接单两种）→ 并入批次
3. 批次列表 → 派车定型（创建配送任务）
4. 扫码/选择批次 → 上货详情页 → 机器人就位显示
5. 打开舱门（任务 30/40 门禁）→ 放货 → 关舱 → 立即配送
6. 配送监控/地图 → 机器人位置
7. 异常处理：重新配送 / 取消退款
8. 售后处理：退款（真实/本地标记）、投诉回复
9. 商品/活动/店铺设置

### 2.4 用户取餐
1. 机器人送达（订单 3 已送达）→ 用户扫码取餐页
2. 打开舱门 → 取餐 → 关舱 → 订单 4 已完成 + 销量结算
3. 40s 自动关舱 → 重新开舱（限次 3 次、限时 10min）
4. 取餐超时：15min 未取 → 一段超时 → 返程再等 → 驳回退款

### 2.5 管理员
1. /admin/ 状态总览：机器人/平台任务/批次/订单/任务/告警正确
2. 雷达图：机器人在线时有点云；离线时占位
3. 任务取消/关闭/作废、删除订单、清理批次
4. 设置页：召唤/开舱/关舱/控制权/点位同步
5. 一键初始化：全部回到干净态（批次 4、无活跃订单、无平台任务）

### 2.6 大屏
- /dashboard/ 5s 轮询：统计/地图/车辆/批次/取餐超时告警正常
