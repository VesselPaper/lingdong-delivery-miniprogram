# 05 · 页面路由清单

最后更新：2026-09-04
说明：对应双端 app.json 的 pages。入参为通过 URL query 或 storage 传入的参数。

## 用户端（18 页，app.json）

| 路径 | 作用 | 入参 / 说明 |
| --- | --- | --- |
| pages/index/index | 首页（tab） | 商品流、搜索入口、购物车角标；onShow 同步 tab selected=0 |
| pages/goods/list | 商城（tab） | storage：goods_category、goods_focus（搜索焦点）；整页不滚动、搜索/店铺名固定，左分类栏与右商品栏各自独立滚动；左分类选中高亮（白底药丸+蓝指示条）并随右栏滚动联动；卡片右侧「+」加购/「− 1 +」步进器，−/+ 点击不跳详情；底部购物车栏悬浮于 tabBar 之上 |
| pages/activity/index | 活动（tab） | 已发布活动列表 |
| pages/goods/detail | 商品详情 | ?id=商品id；步进器数量为 1 时点「−」= 移除该商品 |
| pages/cart/cart | 购物车 | 选中/数量/结算；数量减到 0 自动移除该商品 |
| pages/order/confirm | 确认订单/结算 | ?goods_id=&quantity=（立即购买）或 storage：checkout_items（购物车结算） |
| pages/order/list | 订单列表 | ?status=订单状态（0~7 或空=全部）；storage：order_tab；进入即标记订单动态已读（清我的页红点） |
| pages/order/detail | 订单详情 | ?id=订单id；待接单免费窗口内可取消、超时转取消申请，配送中不可取消；已送达/已完成/配送异常提供「退款/投诉」入口；已送达时「模拟扫码取餐」直达取餐页；展示同批次信息（一车多单：本车共N单/已取X单） |
| pages/order/cancelRequest | 提交取消申请 | ?order_id=；超过免费窗口未配送的订单填写原因提交，由商家判断 |
| pages/delivery/track | 配送追踪 | ?order_id=（可选，缺省自动取最近进行中订单）；每 3 秒轮询；展示同批次进度（共N单/已取X单）；按钮仅「刷新状态」「模拟扫码取餐」不再换行 |
| pages/delivery/pickup | 取餐页 | ?order_id=；打开舱门→取餐→关舱门（40 秒自动关、可重新打开，防未取到餐）；开舱即标记本单已取走（一车多单计数） |
| pages/order/refund | 申请退款/投诉 | ?order_id=；类型 refund/complaint + 原因，退款默认全额 |
| pages/refund/list | 我的售后记录 | 退款/投诉记录、处理状态与商家回复 |
| pages/user/login | 登录 | 微信一键登录 |
| pages/user/profile | 我的（tab） | 订单入口/地址/售后记录/设置；订单图标**内右上角**红点（未读动态：订单到达/状态已接单，已修复错位到页面右上）；onShow 同步 tab selected=3 |
| pages/user/settings | 设置 | 昵称/手机号修改、退出登录 |
| pages/address/list | 收货地址列表 | 新增/编辑/删除/默认 |
| pages/address/edit | 收货地址编辑 | ?id=（编辑，缺省=新增） |

## 商家端（19 页，app.json）

| 路径 | 作用 | 入参 / 说明 |
| --- | --- | --- |
| pages/index/index | 首页（tab） | 进入站点入口、营业状态；onShow 同步 tab selected=0 |
| pages/user/login | 商家登录 | 微信一键登录（role=merchant） |
| pages/shop/home | 工作台（进入站点） | 主面板四态「待接单/待上货/配送中/待取货」+ 异常/售后次面板 + 常用功能入口（商品/活动/历史订单/取消申请/配送监控/设置）；底部居中圆形「扫码上货」按钮（带待处理批次数角标）直达 device/loading |
| pages/orders/list | 订单列表 | ?status=（1 待接单/2 配送中/3 待取货/4 售后/空=全部）；搜索、模拟扫码配单（直达配单页）、接单（接单后弹窗直达配单页） |
| pages/orders/history | 历史订单 | 已完成订单（status=4）、搜索 |
| pages/orders/detail | 订单详情 | ?id=订单id；商品明细、接单、所属批次信息；「去配单/上货」；测试完成配送（批次内整批标记） |
| pages/orders/scanMatch | 配单结果页 | 保留（扫码配单旧入口，当前模拟扫码直接进配单页） |
| pages/orders/aftersale | 售后列表 | tab：全部/待处理/已退款/已拒绝/已处理 |
| pages/orders/aftersaleDetail | 售后详情 | ?id=售后id；同意退款（金额可改）/拒绝/回复投诉 |
| pages/orders/cancelRequests | 取消申请列表 | tab：全部/待处理/已同意/已拒绝 |
| pages/orders/cancelRequestDetail | 取消申请详情 | ?id=申请id；同意取消/拒绝（填理由） |
| pages/device/loading | 配单/上货（一车多单） | 与「我的任务」一致的分层卡片：批次→订单→商品三层卡面分明、商品一行一个完整展示；组单中批次「派车配送」；待上货批次选择/模拟扫码；整批开舱/关舱/派发；展示批次路线、逐单取餐码与全部商品 |
| pages/goods/list | 商品管理 | 上下架、售罄统计 |
| pages/goods/edit | 商品编辑 | ?id=（编辑，缺省=新增）；图片上传；**分类选择器**（选现有分类或「＋新增分类」，接口 /api/merchant/goods/categories） |
| pages/activity/list | 活动管理 | 新建/编辑/发布/下线/删除 |
| pages/activity/edit | 活动编辑 | ?id=（编辑，缺省=新增） |
| pages/delivery/monitor | 配送监控/机器人 | 真实机器人概览 + 执行中任务；每 5 秒轮询；机器人错误卡+重试 |
| pages/shop/settings | 店铺设置 | 营业/歇业、自动接单（营业+自动接单=支付即自动接单并入批次）、退出登录 |
| pages/user/profile | 我的（tab） | 消息/协议/隐私/设置入口；onShow 同步 tab selected=1 |

## 导航与 tab

- 用户端 tabBar（custom）：首页 / 商城 / 活动 / 我的（pages/index、goods/list、activity/index、user/profile）
- 商家端 tabBar（custom）：首页 / 我的（pages/index、user/profile）
- 登录页为非 tab 页，登录成功 switchTab 到首页；退出登录 reLaunch 到登录页。
