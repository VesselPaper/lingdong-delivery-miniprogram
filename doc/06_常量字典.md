# 06 · 常量字典

最后更新：2026-09-03
说明：前后端统一枚举。后端定义在 backend/server.js（ORDER_STATUS）、backend/services/platform.js（STATUS_TEXT、MACHINE_TEXT），前端各页面按此渲染。

## 1. 订单状态（orders.status）

| 值 | 含义 | 说明 |
| --- | --- | --- |
| 0 | 待支付 | 下单未支付，可支付/取消 |
| 1 | 待接单 | 已支付，等待商家接单，可取消 |
| 2 | 配送中 | 已接单，机器人配送中 |
| 3 | 已送达 | 机器人到达取餐点，待取餐 |
| 4 | 已完成 | 确认取餐完成 |
| 5 | 已取消 | 用户取消（仅 0/1 可取消） |
| 6 | 配送异常 | 平台任务失败（上货/送货失败） |

## 2. 配送任务状态码（delivery_tasks.task_status，平台标准对照表）

| 状态码 | 标识 | 中文释义 | 订单联动 |
| --- | --- | --- | --- |
| 0 | QUEUE | 排队中 | - |
| 10 | TASK_RECEIVED | 任务已接收 | - |
| 20 | GO_TO_LOAD_POINT | 去往上货点 | - |
| 30 | ARRIVE_LOAD_POINT | 到达上货点 | - |
| 40 | LOADING | 上货中 | - |
| 50 | LOADED | 已上货 | - |
| 60 | GO_TO_PICKUP_POINT | 去往取货点 | - |
| 70 | ARRIVE_PICKUP_POINT | 到达取货点 | 3 已送达 |
| 80 | COMPLETED | 任务完成 | 4 已完成 |
| 90 | LOAD_FAILED | 上货失败 | 6 配送异常 |
| 100 | PICKUP_FAILED | 取货失败 | 6 配送异常 |
| 110 | CANCELED | 任务取消 | 5 已取消 |
| 120 | LOAD_PENDING | 上货流程挂起 | - |
| 130 | PICKUP_PENDING | 下货流程挂起 | - |
| 140 | WAITING_FOR_PERFECT | 待完善 | - |
| 150 | CLOSED | 任务被关闭 | 5 已取消 |

子状态：
- 70 到达取货点：71 准确到达 / 72 遇阻判定提前到达
- 90 上货失败：91 去位置点失败 / 92 等待上货超时 / 93 等待上货关舱 / 94 去上货途中设备故障 / 95 去位置点超时
- 100 取货失败：101 去位置点失败 / 102 等待取货超时 / 103 机器返回失败 / 104 去送货途中设备故障 / 105 去位置点超时 / 106 召唤打断配送任务
- 130 下货流程挂起：131 送货挂起，返回上货点 / 132 送货挂起，返回待命

## 3. 机器状态码（machineStatus，平台标准对照表）

| 值 | 中文释义 | 说明 |
| --- | --- | --- |
| idle | 空状态 | 设备初次开机时短暂处于此状态 |
| setting | 设置 | 机器人正在执行地图扫描 |
| charging | 正在充电 | 正在充电桩上进行充电 |
| returnChargingPile | 返回充电桩 | 前往充电桩充电的过程中 |
| standby | 待机中 | 正在待机点等待 |
| returnStandby | 前往待机 | 前往待机点的过程中 |
| exception | 异常 | 设备升级失败或发生异常时 |
| lightTask | 召唤 | 正在执行轻任务（前往某个点位） |
| update | 升级 | 设备正在执行版本更新安装时 |
| interaction | 交互 | 设备触发急停按钮或正在被获取控制权 |
| patrol | 巡逻中 | 机器人正在执行巡逻任务 |
| Delivery | 配送中 | 机器人正在执行配送任务 |

兼容键：init 初始化、delivery 配送中、Patrol 巡逻中、remoteDevOps 远程运维、Acceptance 验收（历史/别名）。

设备在线状态（onlineStatus）：1 在线 / 2 离线 / 3 故障

## 5. 平台业务错误码（主要）

### 创建/操作任务拦截（DLV_CTRL）
| 码 | 含义 |
| --- | --- |
| DLV_CTRL_0001 | 设备存在任务，不允许修改货舱类型 |
| DLV_CTRL_0007 | 设备正在被使用 |
| DLV_CTRL_0008 | 手机尾号无法确定任务，请补前三位 |
| DLV_CTRL_0009 | 暂无匹配任务 |
| DLV_CTRL_0010 | 上货验证失败 |
| DLV_CTRL_0015 | 还有其他的人正在取货 |
| DLV_CTRL_0023 | 机器人不允许创建外卖上楼任务 |

### 任务调度（DLV_MGR）
| 码 | 含义 |
| --- | --- |
| DLV_MGR_0001 | 参数不正确 |
| DLV_MGR_0002 | 导航异常（定位低/偏离地图/电量低/急停等，含 _001~_013 细分） |
| DLV_MGR_0003 | 任务拉取不匹配（_001~_005 细分） |
| DLV_MGR_0004 | 轻任务已存在 |
| DLV_MGR_0005 | 暂无配送任务 |
| DLV_MGR_0007 | 任务参数不含舱位字段 |
| DLV_MGR_0014 | 设备没有空闲仓位 |

完整错误码与细分见 项目进度/03_技术记录.md 与 文档/飞书文档/飞书文档.md。

## 6. 后端通用返回码

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数错误 / 业务状态不允许 |
| 401 | 未登录 / 登录失效 |
| 403 | 无权限（非商家访问商家接口） |
| 404 | 数据不存在 |
| 500 | 服务端异常 |
| 501 | 功能未开通（支付通道未配置） |
| 502 | 上游调用失败（微信下单失败、获取机器人失败） |
