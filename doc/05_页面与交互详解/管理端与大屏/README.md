# 管理端与大屏（目录）

浏览器端两个界面，均由后端同端口托管（管理员 `/admin`、大屏 `/dashboard`），免部署、打开即用。

## 管理员网页（/admin）—— 一个页面一个文档

管理员网页（调度台）含登录与会话、三个页面视图（总览 / 配送数据 / 设置）与构建机制，
逐视图拆分为 `管理员网页/` 子目录：

| 文档 | 内容 |
| --- | --- |
| [管理员网页/00_页面骨架与通用机制.md](管理员网页/00_页面骨架与通用机制.md) | index.html 骨架、三层固定布局、导航与三视图映射、标签/分段/搜索/筛选、WS 与通用操作约定 |
| [管理员网页/01_登录与会话.md](管理员网页/01_登录与会话.md) | 账号密码登录、token 存取、401 全局处理、登出/改密、登录限流 |
| [管理员网页/02_总览页.md](管理员网页/02_总览页.md) | 机器人卡片与操作（召唤/开关舱/更多操作）、异常与死锁告警、校园实时地图（admin-map.js）、操作日志（audit_logs）与状态字典 |
| [管理员网页/03_配送数据页.md](管理员网页/03_配送数据页.md) | 批次/订单/任务三标签 × 活跃/历史/全部三分段、卡片式展示、右键菜单（破坏性操作唯一入口）、详情抽屉与状态时间线 |
| [管理员网页/05_设置页.md](管理员网页/05_设置页.md) | 账号（改密/退出）、机器人控制（控制权/平台点位）、危险操作 |
| [管理员网页/06_构建机制.md](管理员网页/06_构建机制.md) | build.js 分片拼接、TARGETS/CUTS、为什么 parts 不能单独运行、已清理的死代码 |
