# 管理端与大屏（目录）

浏览器端两个界面，均由后端同端口托管（管理员 `/admin`、大屏 `/dashboard`），免部署、打开即用。

## 管理员网页（/admin）—— 一个页面一个文档

管理员网页（调度台）含登录与会话、四个页面视图（总览 / 配送任务 / 历史记录 / 设置）与构建机制，
逐视图拆分为 `管理员网页/` 子目录：

| 文档 | 内容 |
| --- | --- |
| [管理员网页/00_页面骨架与通用机制.md](管理员网页/00_页面骨架与通用机制.md) | index.html 骨架、导航与四视图映射、搜索/批量/WS 通用机制、状态色、通用操作约定 |
| [管理员网页/01_登录与会话.md](管理员网页/01_登录与会话.md) | 账号密码登录、token 存取、401 全局处理、登出/改密、登录限流 |
| [管理员网页/02_总览页.md](管理员网页/02_总览页.md) | 机器人卡片、状态字典与告警、校园实时地图（admin-map.js）、机器人操作 |
| [管理员网页/03_配送任务页.md](管理员网页/03_配送任务页.md) | 正在执行/批次/订单三面板渲染、任务操作（删除/清理/作废/展开） |
| [管理员网页/04_历史记录页.md](管理员网页/04_历史记录页.md) | 已完成与已取消的批次/订单/任务三表 |
| [管理员网页/05_设置页.md](管理员网页/05_设置页.md) | 账号（改密/退出）、控制权与点位、危险操作 |
| [管理员网页/06_构建机制.md](管理员网页/06_构建机制.md) | build.js 分片拼接、TARGETS/CUTS、为什么 parts 不能单独运行、存疑项 |
