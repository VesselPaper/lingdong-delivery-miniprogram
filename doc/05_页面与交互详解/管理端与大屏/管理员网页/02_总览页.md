# 管理员网页 · 总览页

总览页（`#page-overview`）包含三个标签：**机器人（卡片 + 校园实时地图）/ 状态字典 / 异常与操作日志**，
是调度台的默认落地页，重点监控机器人状态、异常与死锁。

## 机器人卡片

`04-overview-ws.js → renderRobotCard`，WS `live` 事件每 ~2.5s 原地刷新（不整页重绘）：

| 字段元素 | 内容 |
|---|---|
| `#rSn / #robotTag` | 设备编号；在线 / 离线 / 无设备 |
| `#rBattery` | 电量百分比 |
| `#rMachine / #rMachineAge` | 机器状态（`machine_status` + `MACHINE_TEXT` 中文）与状态停留时长（`ageLabel`） |
| `#rStocks / #rMap / #rFloor / #rStatusTime` | 舱位占用（`busy_stocks`）、地图 id（`curr_map_id`）、楼层与楼栋、状态更新时间 |

## 状态字典与告警

- `renderOverview`：`#dictBox` 渲染 `TASK_STATUS`（任务状态码）与 `MACHINE_TEXT`（机器状态）字典；
- `#alertCount / #alertsBox` 展示后端死锁/异常检测结果（`alerts`，warn/bad 分级着色）；
- `#log` 操作日志由 `01-core.js → log` 写入（时间戳 + 分级样式）。

## 总览页校园实时地图（admin-map.js）

总览「机器人」标签右侧是 Leaflet 实时地图，由 `管理员网页/js/parts/map/*.js` 五片实现（与 admin.js 同构的 IIFE 分片）：

- **坐标系**（`01-init.js`）：Leaflet `CRS.Simple` 像素坐标，平台雷达地图 PNG 为唯一底图；按平台 map 元数据
  `{ width, height, resolution, origin }` 做像素级对齐，`toPixel` 把世界坐标（米）线性映射为图像像素（y 翻转），
  点位 / 路网 / 无人车 / 配送站位与雷达图严格对齐，不再用 bbox 外包框或经纬度近似；
- **底图**：`/api/dashboard/map-image`（与可视化大屏同一后端代理地址）；首次 `fitBounds` 显示全图并把最小缩放锁为全图大小（`applyRadar`）；
- **静态层**（`02-static.js`）：`updateLandmarks` 按类型分色渲染平台点位——取货点蓝 `#1d5bd6`、上货点橙 `#e8890c`、
  充电点绿 `#2f9e44`、巡逻点紫（circleMarker + 悬停泡泡），名字文字常驻可见；`usableLandmarks` 剔除名为「固定路径」的噪音点位；
  `updateRoutes` 把配送站位按停靠顺序画成编号钉（`stopSvg`）；
- **车辆层**（`03-cars.js`）：`updateCars` 按 `device_sn` 复用标记，SVG 铲形俯视车图标 + 车名（尾 6 位），车头随航向
  `deg = HEADING_OFFSET - θ` 旋转；`applyRouteFocus` 与 `highlightBatchDetail / clearBatchFocus` 实现批次聚焦
  （目标批次站位高亮、其余降透明，并 fitBounds 定位）；
- **渲染与拉取**（`04-render.js`）：`poll` 拉 `GET /api/admin/map`（adminGuard 鉴权，服务端 3 秒缓存）→ `renderMap`
  （写 `META`、铺雷达图、更新静态层与车辆、刷新底栏 `#mapFoot` 统计）；`setMask` 控制加载/失败遮罩；
- **实时层**（`05-live.js`）：`window.mapOnLive` 由 admin.js 的 WS live 事件调用，原地只更新小车与实时心跳底栏
  （`#mapFoot` 显示各车坐标与时间戳），不整体重拉；`trackCar` 记录每台车最近 80 个位置画绿色虚线轨迹；
  `ensureFollowBtn` 提供「跟随小车」按钮（约 12m×12m 视野 + 边沿跟随，小车驶出中部 33% 安全区才平移追过去）；
  `invalidateAdminMap` 在标签切回时刷新尺寸；`reloadAdminMap`（= poll）在 WS 重连/初次加载时拉一次完整地图；
  `adminMapDebug` 为排障钩子；「回到校园」按钮 `#mapResetBtn` 复位到全图。

## 总览页操作（交互清单）

机器人卡片上的操作，均经 `07-ops.js → run / confirmRun` 执行（统一落账 + `refresh()`）：

| 操作 | 触发 | 函数（文件） | 接口（均 `/api/admin` 前缀） |
|---|---|---|---|
| 召唤机器人 | 总览·机器人卡 | `07-ops.js → actSummon` | `GET /robot/summon-targets` 取上货/充电/取货点 → `openPickModal` 弹窗选择 → `POST /robot/summon { device_sn, landmark_id }`（会中断正在执行的配送任务） |
| 开关舱门 | 总览·机器人卡 | `actDrawerPick` | 弹窗选开/关舱 → `POST /drawer { device_sn, cmd }`（drawerCtrl 独立控制，不影响任务状态） |
| 停止（驻停） | 总览·机器人卡 | `actStop` | `POST /robot/stop { device_sn, stop_time: 30 }`，原地驻停 30 秒后自动恢复 |
| 继续工作 | 总览·机器人卡 | `actRecover` | `POST /robot/recover { device_sn }`，恢复其任务执行 |
| 停止并取消任务 | 总览·机器人卡 | `actStopCancel` | `POST /robot/stop-cancel { device_sn }`（先关活跃任务再驻停，舱内有货自动开舱，不可撤销） |
