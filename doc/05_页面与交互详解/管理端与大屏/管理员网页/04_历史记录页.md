# 管理员网页 · 历史记录页

历史记录页（`#page-history`）包含三个标签：**批次 / 订单 / 任务**，展示已完成与已取消的实体，
工具栏含搜索（`#historySearch`，160ms 防抖）与状态筛选。点击左侧导航「历史记录」进入（`navTo('history')`）。

## 表格渲染

- `05-render-tables.js → renderHistoryPage`：按 `historyTab` 分发到批次 / 订单 / 任务三表；
- `renderLocalTaskPanel`：历史任务表——本地任务：订单/批次/平台任务 ID、状态停留、设备；
- 批次表两页共用 `renderBatchPanel`（路线文本、当前停靠、配送进度、展开箭头懒加载批内订单），详见
  [03_配送任务页.md](03_配送任务页.md)；
- 历史批次/订单/任务表支持行内复制编号、按需批量操作（`runBulkBatch / runBulkTask`），
  通用操作见 [00_页面骨架与通用机制.md](00_页面骨架与通用机制.md)「通用操作约定」。

## 数据来源

`06-refresh-token.js → refresh` 一次性拉 `GET /api/admin/state`（`buildAdminState` 聚合），
历史数据包含在 `state` 的本地批次/订单/任务列表中，前端按状态过滤出「已完成 / 已取消」部分；
实时变化由 WS `state_changed` 事件驱动 `refresh()`。
