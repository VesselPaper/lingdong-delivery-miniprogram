# 管理员网页 · 商家管理页

商家管理页（`#page-merchants`）是侧栏第 4 个导航项「商家管理」（`navTo('merchants')`），
用于**商家入驻邀请码**管理：创建商家 → 生成一次性邀请码 → 线下发给商家 → 商家端登录绑定微信 →
管理员可查看绑定状态、吊销、重新启用、解绑。
2026-09-24 上线前改造：env 共享码兜底停用后，商家权限**只认 merchant_invites 表**，本页是唯一的管理入口。

## 页面布局

| 区域 | 元素 | 内容 |
|---|---|---|
| 页头工具栏 | `#merchantCount` | 商家总数 |
| | `#merchantReload` | 刷新按钮 → `loadMerchants()` |
| 左卡：创建 | `#merchantName` | 店名（必填） |
| | `#merchantCode` | 自定义邀请码（留空自动生成随机码，推荐） |
| | `#merchantNote` | 备注（负责人/电话/位置，选填） |
| | `#merchantCreate` | 「生成邀请码」按钮 |
| | `#merchantCreateMsg` | 生成结果：**明文码只显示这一次** |
| 右卡：列表 | `#merchantTag` | 邀请码可用性（configured 时显示「邀请码可用」，否则标红） |
| | `#merchantList` | 商家行：店名、备注、创建时间、绑定状态 + 操作按钮（吊销/启用/解绑） |

## 前端逻辑（`管理员网页/js/parts/admin/09-merchants.js`）

- `loadMerchants()` → `GET /api/admin/merchants` → `renderMerchants()`；进入本页（`navTo('merchants')`）或点刷新时调用。
- `merchantCreate()` → `POST /api/admin/merchants/create { name, code?, note? }`：
  后端返回 `{ id, code }`（明文码**只此一次**），前端在 `#merchantCreateMsg` 用 `.mono` 展示并提示立即复制；
  成功后清空输入并重载列表。
- `merchantRevoke(id)` / `merchantActivate(id)` / `merchantUnbind(id)` →
  `POST /api/admin/merchants/revoke|activate|unbind { id }`；吊销/解绑走 `openConfirmModal` 二次确认。
- 后端全部接口经 `adminGuard` 鉴权 + `audit` 审计（动作 `admin/merchant-create|revoke|activate|unbind`）。

## 后端接口（`backend/domains/admin/routes.js`）

| 接口 | 说明 |
|---|---|
| `GET /api/admin/merchants` | 列表：id / name / note / bound（是否绑定）/ bound_openid（脱敏）/ active / created_at；`configured` 表示表里是否有有效码 |
| `POST /api/admin/merchants/create` | 创建：店名必填；body.code 可自定义（≥4 位），留空自动生成；同码已有效则 400；已吊销的同码自动复用（重新启用+清绑定） |
| `POST /api/admin/merchants/revoke` | 吊销（active=0），已绑定商家登录不受影响（已是商家免码续登） |
| `POST /api/admin/merchants/activate` | 重新启用（active=1） |
| `POST /api/admin/merchants/unbind` | 解绑 openid（未绑定则 400） |

## 邀请码机制说明

- 库中只存 `sha256(邀请码.toUpperCase())`（`backend/services/merchantInvite.js → sha`），明文不落库；
- 商家端登录（`backend/domains/user/service.js → login`）校验邀请码：`merchant_invites` 表有效 + 未绑定其他账号
  （真实登录态首次使用自动绑定 openid，一码一店）；env `MERCHANT_INVITE_CODE` 已停用；
- 命令行替代入口：`backend/tools/merchant_invite.js`（add/list/revoke/activate/unbind），与网页操作等价。
