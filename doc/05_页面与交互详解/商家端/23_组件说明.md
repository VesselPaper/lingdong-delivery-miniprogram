# 23_组件说明
> 页面路径：23_组件说明（商家端小程序）

## 组件说明（简述）

| 组件 | 目录 | props / 事件 | 用途与关键点 |
| --- | --- | --- | --- |
| batch-card 批次卡 | components/batch-card | props：`b`（批次对象，订单需预置 `stClass` 与 `displayStatus`）、`showNo/showProgress/showGoods/orderTap/action/selectText`；事件：`cardtap(b) / select(b) / dispatch(b) / ordertap(order)` | 一车多单批次卡面：批次短号 + 完整编号（showNo 弱化）+ 标签区（「已锁定·待配送」/ 状态 / N 单）+ 机器人/件数/路线/进度（已取 X/N）信息行 + 批次内订单子卡（取餐码、收餐人、「召回失败·需人工」标签、商品明细）+ 底部 CTA；`action='select'` 渲染「上货」按钮（`robotBusy` 时渲染禁用/忙提示，`dispatchMark` 时「已装货 · 待配送（车忙）」）、`action='dispatch'` 渲染「派车配送（N 单）」；订单子卡与按钮均 `catchtap` 防冒泡，整卡 `bindtap` 触发 `cardtap` |
| order-card 订单卡 | components/order-card | props：`order`（含 daily_seq/stClass/displayStatus/items/landmark_name/batch/created_time/total_amount/status/payed）；事件：`tap(order)`；插槽 | 扁平订单卡（任务页待接单/异常用）：订单短号 + 已收款标签 + 状态文字 + 商品明细行 + 送达/批次/下单时间 + 合计；操作按钮由页面经插槽注入（按钮区 `catchtap` 防冒泡，点按钮不触卡 tap） |
| goods-row 商品行 | components/goods-row | props：`image/name/price/qty` | 商品明细行（固定尺寸图盒 + 内部 image 100% 铺满防拉伸，无图用图标兜底 + 名称 + ¥价格 + x数量） |
| status-text 状态文字 | components/status-text | props：`cls`（gray/orange/blue/green/red）、`text` | 按状态色板着色（复用 app.wxss `.st-*` 类） |
| search-box 搜索框 | components/search-box | props：`value/placeholder`；事件：`input(value) / confirm(value)` | 统一搜索框（t-design 搜索图标 + input，`confirm-type="search"`，复用 `.search-row/.search-box` 样式） |
| empty-view 空态 | components/empty-view | props：`show/text/icon` | 统一空态占位（图标 + 文案），`show` 控制显隐 |
