# 售后列表（全部/待处理/已退款/已拒绝/已处理）
> 页面路径：pages/orders/aftersale（商家端小程序）


- **数据来源**：`onShow` → `load()` → GET /api/merchant/refunds（`active` 非空时拼 `?status=`，取值 '' / 0 / 3 / 2 / 4）。
- **页面构成**：顶部五分类 tab（全部 / 待处理 / 已退款 / 已拒绝 / 已处理）；列表卡面 = 类型标签（`type === 'complaint' ? '投诉' : '退款'`）+ 状态文字（待处理标黄 warn）+ 订单号 + 申请金额（退款类型）+ 原因（单行省略）+ 处理回复（已处理时）。
- **交互清单**：

| 按钮/交互 | 触发函数 | 行为与调用的接口 | 后续链路/跳转 |
| --- | --- | --- | --- |
| 五分类 tab | onTab | 更新 `active` 后 `load()` | — |
| 售后单卡 | goDetail | 读 `data-id` | navigateTo /pages/orders/aftersaleDetail?id= |

- **重点链路**：售后与退款共用列表接口，前端按类型与状态渲染不同字段行；tab 状态值约定与详情处理接口 `action` 语义对应（0 待处理 / 2 已拒绝 / 3 已退款 / 4 已处理）。
- **状态与边界**：请求带 `silent`（弱网不弹错）；空列表显示「暂无售后单」。
