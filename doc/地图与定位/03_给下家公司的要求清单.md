# 给候选供应商的要求清单

本文件可以直接发给候选供应商，也可以作为技术附件底稿。内部依据与推导见 `01`（36 问、量化条款）、`02`（复盘与选型标准）和 `04`（精度定标：误差预算、三档门槛、分区依据），本文不重复论证过程。**精度与地图规模的数值以 `04` 为准**（2026-10-26 更新：停靠 10 cm、图-实地 5 cm、分区 ≤25 万㎡）。

## 0. 怎么用

- 分五段：**A 门槛**（不满足不进入下一轮）→ **B 硬指标**（POC 与合同）→ **C 接口契约** → **D 商务** → **E 现场要求**。
- B、C 两段的数字会原样写进技术附件，请在报价前逐条确认能否做到；做不到的请直接说明，不要留到 POC 再发现。
- 另有 36 项问答清单用于座谈，按需索取。
- 项目现状：

| 项 | 情况 |
| --- | --- |
| 场地 | 四川师范大学成龙校区，约 67 万㎡（829 亩），跨东苑 / 西苑两个片区 |
| 点位 | 首期 20 个，扩展预留 50 个 |
| 单量 | 集中在午、晚两个高峰，寒暑假人流骤变 |
| 车队 | 先 1 台验证，方案必须支持扩到 4 台以上，不得因加车改架构 |
| 过渡 | 新旧系统双轨并行 30 天，需要点位与订单的映射 |

## A. 门槛（4 条，一票否决）

| # | 要求 | 判据 |
| --- | --- | --- |
| A1 | 同类场景 | 有 ≥40 万㎡ 开放式园区 / 校园的**在运营**案例，可实地走访；不接受只看宣传片 |
| A2 | 地图单元 | 园区级**分区**地图：单区 ≤25 万㎡、支持 ≥4 区拼接与跨区任务连续下发；若接口仍是"楼栋 → 楼层地图"、或只能"一张图管全校且不分区"，不进入下一轮 |
| A3 | 开发条件 | 提供完整 OpenAPI + 沙箱 + 模拟车，允许在没有真车的情况下联调与回归 |
| A4 | 调度权 | 平台自身调度可关闭，提供"只执行、不决策"模式 |

## B. 硬指标（12 条，写进 POC 与合同）

| # | 项 | 要求 |
| --- | --- | --- |
| B1 | 图幅与分辨率 | 单区 ≥25 万㎡，且**分辨率不得低于 0.05 m/px**（≈1 亿像素）；本校 67 万㎡ 按 3–4 区建，跨区任务连续下发。只报"多少平方米"不算，要报"0.05 m/px 下的单图像素上限" |
| B2 | 图-实地一致性（建图绝对精度） | ≤5 cm（95%），最大 ≤10 cm；10 个检查点用 RTK 或全站仪打，与图上坐标比。**这是主指标，比"定位精度"更能决定停得准不准** |
| B3 | 相对精度 | 100 m 内两点距离误差 ≤5 cm（≤0.05%）；500 m 区内对角 ≤10 cm；图上量距 vs 实地 3 段，误差 ≤0.1% |
| B4 | 跨区一致性 | 重叠区同名点 ≤5 cm；跨区同一物理点 ≤10 cm（95%）；重扫不得静默改老点位 |
| B5 | 停靠偏差 | **≤10 cm（95%）、最大 ≤15 cm、姿态 ≤5°**；10 次重复停靠 1σ ≤5 cm；静止 10 min 2σ ≤2 cm |
| B6 | 建图 | 2 天内扫完东苑 + 西苑，一次成功、不崩、不丢段；交建图报告（含环路闭合误差） |
| B7 | 扩建与换图 | 支持增量扩建、失败可回滚上一版；重扫不得静默改老点位坐标，要改必须给迁移清单 |
| B8 | 定位质量 | 位姿 ≥10 Hz，带时间戳、置信度/协方差、当前地图 ID；丢定位要告警；恢复 ≤10 s，无需人到场 |
| B9 | 多单 | 单次 ≥8 单（舱底 ≥4500 cm² 可放宽到 15 单）；全程 ≤45 min；每停靠 ≤2 min；**有序多停靠，顺序由调用方锁定** |
| B10 | 舱位 | 可分格且隔板可拆可调；可指定开某一格；每格有独立状态（放没放、取没取）；系统能读到当前分格配置 |
| B11 | 商品占用 | 支持按**底面尺寸**校验（外卖几乎不能叠，容积不算数），装不下要在下单时算出来，不是到现场才发现 |
| B12 | 车队 | 支持 ≥4 台同时调度；车辆间避让与任务分配可用平台能力，也可由我们接管 |

## C. 舱体与场景（4 条，现场实测）

| # | 项 | 要求 |
| --- | --- | --- |
| C1 | 人群 | 被围住时 ≤3 min 能自行或远程脱困，不阻塞通道；能主动上报"被困"，不能一直显示"配送中" |
| C2 | 雨天 | 整机 ≥IPX4 + 第三方淋雨报告；舱底有排水、货物离底架空 10 mm、盖内侧不挂水；感知降级必须主动告知 |
| C3 | 舱门 | 侧开 / 抽屉优先；上翻盖必须带挡水沿 + 导水槽；开门时舱口不朝天 |
| C4 | 工作环境 | 夜间、树荫、人车混行、假期人流突变；工作温度下限 ≤-5℃（成都冬季） |

## D. 接口契约（6 条，缺一项算交付不合格）

| # | 项 | 要求 |
| --- | --- | --- |
| D1 | 地图元数据 | `resolution` / `origin` / `mapVersion` / 校验和 / 更新时间，随接口交付 |
| D2 | 位姿与回调 | ≥1 Hz 位姿；到点、开格、取完、关格各有回调，不是只有一个"任务完成" |
| D3 | 任务原语 | ① 有序多停靠（可多取多送）② 单点原子操作（跳过 / 插入 / 改停留）③ 舱位寻址 ④ 按点按格回调 ⑤ 调度可关闭 ⑥ 沙箱 + 模拟车 |
| D4 | 图层 | 禁行区 / 禁行线与点位同坐标系，可导出 |
| D5 | 数据导出 | 订单轨迹、任务日志可导出 CSV / JSON |
| D6 | 退出交付 | 合同终止时交地图（`map.yaml` + PNG）、点位（CSV）、历史轨迹；过渡期 30 天双轨运行 |

## E. 商务（5 条）

| # | 项 | 要求 |
| --- | --- | --- |
| E1 | 验收 | 明确测量方法（RTK / 全站仪 / 卷尺 + 喷漆点）、谁出测量报告、不达标整改时限 |
| E2 | SLA | 故障响应与到场时限、是否驻场、升级路径、工单号可查 |
| E3 | 价格 | 一次性 + 年服务费 + 扩建单价 + 备件价；软件升级是否另收费 |
| E4 | 数据归属 | 地图、轨迹、订单数据归甲方，不得用于训练或转售 |
| E5 | 车辆处置 | 合同终止时车辆残值或回购方案 |

## F. 现场要求（3 条）

| # | 要求 | 说明 |
| --- | --- | --- |
| F1 | 当场建图 | 座谈当天带自己的车和系统，现场建一张 ≥4 万㎡ 的图（200×200 m），**当场演示保存、重载、再建相邻一区并拼接**，允许我们旁观与计时 |
| F2 | 三个书面回答 | 被围住时的具体策略、雨天有没有 IP / 淋雨报告、单均时长实测值。三项都给不出数据，视同与现有方案无差异 |
| F3 | 原始数据交付 | POC 期间提供：10 分钟静止 pose 日志（算抖动）、同点 10 次自动停靠的 pose 记录、建图结束的环路闭合报告。**我们按自己的口径复算，不采信截图** |
