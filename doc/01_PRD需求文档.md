# 01 · 需求文档（PRD）

最后更新：2026-09-03
适用范围：送餐无人车微信小程序（用户端 + 商家端 + 后端）
来源：项目进度/04\_需求清单.md（R1~R6）、文档/小程序技术方案草案.md、沟通记录

## 1. 项目概述

四川师范大学校内引入无人送餐车，面向师生提供无人化外卖配送。本小程序是核心下单与配送追踪载体，分为：
用户端：学生点餐、支付、查看配送进度与机器人位置、取餐验证。
商家端：零栋铺子管理商品、处理订单、上货确认、配送监控、活动发布。

## 2. 角色定义

| 角色             | 使用端 | 说明                                                                 |
| ---------------- | ------ | -------------------------------------------------------------------- |
| 学生（用户）     | 用户端 | 浏览商品、加购、下单支付、查看订单与配送、凭取餐码取餐、管理收货地址 |
| 商家（零栋铺子） | 商家端 | 商品上下架/库存价格、接单、上货、配送监控、营业/自动接单、活动发布   |
| 系统后端         | -      | 业务逻辑、微信登录/支付、开放物流平台对接、回调接收                  |
| 开放物流平台     | -      | 机器人任务调度、状态上报、位置数据（robox）                          |

## 3. 核心业务流程

### 3.1 主流程：下单配送闭环

学生下单 → 微信支付 → 商家接单（扫码配单）→ 机器人到店上货 → 机器人配送 → 到达取餐点 → 学生凭取餐码开舱取餐 → 订单完成

1. 学生浏览商品，加购 / 立即购买。
2. 确认订单：选收货地址（自动带出点位/姓名/电话）→ 选送达点位 → 选预计送达时间 → 提交。
3. 微信支付（JSAPI）；支付成功后订单变为「待接单」。
4. 商家端收到待接单 → 接单（后端创建配送任务，店铺歇业时拒绝）。
5. 开放物流平台调度机器人：前往上货点（零栋铺子）→ 上货 → 前往送餐点 → 到达。
6. 学生端配送追踪页查看进度与位置；到达后订单「已送达」。
7. 学生在机器人屏幕输入 / 扫码取餐码 → 确认取餐 → 订单「已完成」。

### 3.2 支付流程

后端统一下单（微信支付 V3 JSAPI）→ 返回 payParams → 前端拉起收银台 → 微信服务器回调 /api/pay/notify → 订单置为已支付 → 前端轮询确认已收款。

### 3.3 配送状态联动

平台任务状态 → 订单状态：

- 任务 70 到达取餐点 → 订单 3 已送达
- 任务 80 完成 → 订单 4 已完成
- 任务 110/150 取消/关闭 → 订单 5 已取消
- 任务 90/100 失败系 → 订单 6 配送异常

## 6. 交互逻辑要点

- 未登录：用户端访问需登录接口时跳登录页；商家端启动无 token 跳登录页；接口 401 清 token 回登录页。
- 结算页与收货地址联动：进入自动选默认地址，回填点位+姓名+电话；从地址管理返回自动刷新。
- 店铺歇业：商家端后端拒绝接单，前端按钮置灰提示。
- 配送追踪：用户端每 3 秒轮询；商家配送监控每 5 秒轮询；机器人接口失败以错误卡呈现（静默不弹 toast）。
- 支付成功：前端轮询订单确认已收款（支付回调可能延迟）。
- 取餐码：机器人到达后须匹配 pickup_code 才能确认取餐。
- 购物车数量（商城/详情/购物车页三处统一）：数量为 1 时点「−」= 移除该商品（调 /cart/remove）；仅数量为 0 时「−」置灰不可点。
- 商城页交互：整页不滚动、搜索框/店铺名固定，左分类栏与右商品栏各自独立滚动；左分类选中高亮（白底药丸+蓝指示条）并随右栏滚动联动；卡片右侧「+」加购、加购后变「− 1 +」步进器，−/+ 用 catchtap 阻止冒泡、不跳详情；底部购物车栏悬浮于 tabBar 之上，列表内容预留底部滚动余量。
- 取餐（取餐页）：打开舱门→取餐→关舱门；40 秒未关舱平台自动关，可重新打开舱门（防未取到餐）。
- 订单取消规则：下单后免费取消窗口内（默认 10 分钟）可直接取消，**不论商家是否接单**、只要未真正开始配送（任务状态 < 50）；超过窗口且未配送（待支付/待接单）须提交「取消申请」由商家判断（同意→订单取消，拒绝→订单继续，用户可再次申请）；配送中不支持取消，送达后可走退款/投诉（退货退款）。

## 7. 异常场景

| 场景                            | 处理                                                    |
| ------------------------------- | ------------------------------------------------------- |
| 支付失败 / 用户取消支付         | 订单保持「待支付」，可在订单列表/详情继续支付           |
| 支付回调未达                    | 前端轮询订单状态兜底确认已收款                          |
| 店铺歇业时接单                  | 后端拒绝（400 店铺歇业中），前端置灰                    |
| 机器人配送失败（上货/送货失败） | 订单转「配送异常」（6），任务列表展示失败状态           |
| 机器人还未送达就点取餐          | 后端拒绝（机器人还未送达）                              |
| 取餐码不匹配                    | 后端拒绝（取餐码不匹配）                                |
| 配送中订单取消                  | 后端拒绝；仅免费窗口内且未真正开始配送可取消；配送中须送达后走退款/投诉 |
| 超过免费取消窗口               | 不可直接取消，引导提交「取消申请」，由商家判断是否同意                  |
| 平台未配置 / 机器人接口失败     | 商家机器人页显示错误卡 + 重试按钮                       |
| 开放物流平台凭据缺失            | 接单创建任务提示「未配置平台凭据」，任务不下发          |
| 商品库存为 0                    | 商品不可加购（前端售罄态）                              |
