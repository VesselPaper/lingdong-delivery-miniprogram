## 3. 后台配置（发布前必做）

### 3.1 合法域名（开发→开发管理→开发设置→服务器域名）

| 类别 | 配置值 | 说明 |
|---|---|---|
| request 合法域名 | `https://api.lingdong.cn` | 后端 API（必须 HTTPS、已备案） |
| uploadFile 合法域名 | `https://api.lingdong.cn` | 商家上传商品图 |
| downloadFile 合法域名 | `https://api.lingdong.cn` | 图片下载；**另加平台地图 OSS 域名** `https://eventec-k8s-pro.oss-cn-beijing.aliyuncs.com`（交接文档2：地图图片来自该 OSS，签名直链约 1 小时过期，后端已缓存地址） |
| socket 合法域名 | `wss://api.lingdong.cn` | WebSocket `/ws`（Nginx 需支持 Upgrade，见 02 篇） |

- 开发阶段：开发者工具勾选「不校验合法域名」即可连本机/局域网，不受此限制（`README.md` §二）。

### 3.2 其它后台项
- 类目：按「食品/餐饮」或学校服务相关类目选，与页面内容匹配（避免审核被打回）；需商家资质材料的先备好。
- 隐私协议/用户协议：小程序有「用户隐私保护指引」填写；登录会收集 openid，需如实申报。
- 版本管理：见第 5 节。

## 4. 上传与发布流程

### 4.1 上传代码（微信开发者工具）
1. 双端 `utils/config.js` 的 `CURRENT` 切到 `'prod'`（baseUrl 指向 `https://api.lingdong.cn/api`，见 04 篇）；
2. 开发者工具右上角「上传」→ 填版本号（如 `1.0.0`）与备注；
3. 上传成功后，在微信公众平台「版本管理」看到该版本。

### 4.2 体验版（免审核，先给团队测）
- 版本管理页把刚上传的版本设为「体验版」→ 生成体验版二维码 → 发给体验成员（已在「成员管理」添加）扫码使用。
- 体验版与正式版功能一致，**不需要审核**，是上线前的联调/验收环境。

### 4.3 提交审核
- 在「版本管理 → 开发版本」点「提交审核」→ 填写功能页面（选取餐/订单等核心页）、测试账号备注（若有）、隐私接口说明；
- 审核时长：一般 **几小时~1-2 天**（首审可能更慢；多次违规会加长）；
- 审核期间开发版/体验版不受影响，可以继续改。

### 4.4 发布
- 审核通过后「发布」→ 全部用户生效；可先用「分阶段发布（灰度）」小比例验证再全量。
- 发布后**小程序码（getwxacodeunlimit）对普通用户扫码才生效**（此前只有开发者/体验成员能扫开）——与「扫码直达取餐」功能联动，见功能文档。

## 5. 版本回退（紧急 bug 兜底）

- 微信公众平台「版本管理 → 线上版本」支持**回退到上一个发布版本**（一键，秒级生效）。
- 流程：发现线上大 bug → 后台回退 → 用户恢复上一版 → 再修代码重新走 4.1~4.4。
- 后端回退见 06 篇（git 回退 + pm2 reload）。
