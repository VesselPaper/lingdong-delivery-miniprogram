## 3. 后台配置（发布前必做）

### 3.1 合法域名（开发→开发管理→开发设置→服务器域名）

| 类别 | 配置值 |
|---|---|
| request | https://api.lingdong.cn |
| uploadFile | https://api.lingdong.cn |
| downloadFile | https://api.lingdong.cn + 地图 OSS https://eventec-k8s-pro.oss-cn-beijing.aliyuncs.com |
| socket | wss://api.lingdong.cn |

开发阶段：开发者工具勾选「不校验合法域名」即可连本机/局域网。

### 3.2 其它后台项

- 类目：按「食品/餐饮」或学校服务类目选，与页面内容匹配，需商家资质材料的先备好。
- 隐私协议/用户协议：填写「用户隐私保护指引」，如实申报收集 openid。
- 版本管理：见第 5 节。

## 4. 上传与发布流程

### 4.1 上传代码

1. 双端 utils/config.js 的 CURRENT 切到 'prod'（见 04 篇）
2. 开发者工具右上角「上传」→ 填版本号与备注
3. 微信公众平台「版本管理」可见该版本

### 4.2 体验版（免审核，先给团队测）

版本管理页把上传版本设为体验版 → 生成二维码 → 发体验成员扫码使用。体验版与正式版功能一致，不需审核。

### 4.3 提交审核

版本管理 → 开发版本 → 提交审核 → 填功能页面、测试账号备注、隐私接口说明。审核一般几小时~1-2 天，首审更慢。

### 4.4 发布

审核通过后发布，可先分阶段发布（灰度）再全量。发布后小程序码对普通用户扫码才生效。

## 5. 版本回退

微信公众平台「版本管理 → 线上版本」支持一键回退到上一发布版本，秒级生效。后端回退见 06 篇。
