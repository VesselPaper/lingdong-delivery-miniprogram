最后更新：2026-09-24
说明：本项目（四川师范大学校内无人送餐车 · 双微信小程序 + Node 后端）**真实部署上线**的完整操作文档。从「能不能上线」到「怎么上线」「上线后怎么改」，按实操顺序组织；每篇给出具体步骤、命令、检查清单，并标注对应代码/配置出处。
配套文档：`doc/02_系统架构与运行.md`（架构与环境变量全表）、`doc/07_配送平台对接.md`（robox 平台）、`agent/agent交接文档/会话交接文档/交接文档12.md`（当前现状快照）。

## 上线前必读结论（一句话版）

- 本项目**可以真实上线**：后端是单 Node 进程 + SQLite（零外部数据库），学生规模 2 核 4G 云服务器绰绰有余。
- **硬前提只有两件事**：① 域名 + ICP 备案 + HTTPS（微信小程序 request 合法域名强制要求）；② 小程序至少处于**体验版/已发布**状态（小程序码扫码直达才对所有用户生效）。
- **上线不锁死开发**：本地开发、体验版联调、后端 pm2 reload 都与现在几乎一样，仅"正式发布"多一道微信审核。
- 凭据类（WX_SECRET、微信支付商户、平台 appid/secret）**不进仓库**，全部放服务器 `backend/.env`（线下从负责人获取）。

## 执行顺序建议（总览）

```
第 0 步（现在就能做）   ：买服务器 + 注册域名 → 启动 ICP 备案（周期 2-4 周，最耗时，先办）
第 1 步                  ：服务器装 Node 22+ → 部署后端代码 → pm2 守护 → 本机验证 /api/goods/list
第 2 步                  ：域名解析 + Nginx + HTTPS 证书（443 → 127.0.0.1:3000）
第 3 步                  ：配生产 .env（真实凭据）+ 双端 config.js 切 prod 域名
第 4 步                  ：小程序后台配合法域名 → 上传体验版联调（团队复测）
第 5 步                  ：扫码直达取餐功能联调（开发者工具模拟 scene + 体验版真机）
第 6 步                  ：提交正式版审核 → 发布（可灰度）→ 监控
第 7 步                  ：每日备份 cron + 上线后迭代流程（见 06）
```

> 时间线提示：**ICP 备案是唯一不可压缩的硬等待**（约 2-4 周，需域名注册商/云厂商提交，负责人证件）。建议今天下单服务器 + 注册域名，让备案先跑起来，其余步骤并行推进。
