# 上线计划（目录）

最后更新：2026-09-26

四川师范大学校内无人送餐车 · 双微信小程序 + Node 后端真实部署上线的完整操作文档，按实操顺序组织。

配套文档：`doc/02_系统架构与运行.md`、`doc/07_配送平台对接.md`。

## 结论

- 项目可真实上线：后端单 Node 进程 + SQLite，2 核 4G 云服务器足够。
- 硬前提只有两件：① 域名 + ICP 备案 + HTTPS；② 小程序处于体验版/已发布状态。
- 上线不锁死开发：本地开发、体验版联调、pm2 reload 均照旧，仅正式发布多一道微信审核。
- 凭据不进仓库，全部放服务器 `backend/.env`。

## 执行顺序

```
第 0 步  买服务器 + 注册域名 → 启动 ICP 备案（2-4 周，最耗时，先办）
第 1 步  服务器装 Node 22+ → 部署后端 → pm2 守护 → 验证 /api/goods/list
第 2 步  域名解析 + Nginx + HTTPS（443 → 127.0.0.1:3000）
第 3 步  配生产 .env（真实凭据）+ 双端 config.js 切 prod
第 4 步  小程序后台配合法域名 → 上传体验版联调
第 5 步  扫码直达取餐功能联调
第 6 步  提交正式版审核 → 发布（可灰度）→ 监控
第 7 步  每日备份 cron + 上线后迭代
```

> ICP 备案是唯一不可压缩的硬等待（2-4 周）。建议先下单服务器 + 注册域名，让备案先跑起来。
