# 01 · 部署架构与服务器选型

最后更新：2026-09-26

## 1. 部署拓扑

```
        学生微信 · 商家微信（扫小程序码/普通打开）
                     │ HTTPS（443）
                     ▼
        ┌───────────────────────┐
        │  云服务器（1 台）        │
        │  Nginx（443 终止 TLS）  │
        │    │ 反向代理           │
        │    ▼                   │
        │  node server.js        │ ← pm2/systemd 守护
        │  监听 127.0.0.1:3000   │
        │  /api /admin /dashboard│
        │  /ws /uploads SQLite   │
        └───────────────────────┘
                     │
                     ▼
         robox 开放物流平台（已对接）
         微信支付（生产必配）
         微信 code2session（真实登录）
```

- 单进程三服务同端口：API + 管理员网页 + 大屏全部由 3000 端口一个进程托管，Nginx 转发 `/` 即可。
- 数据库 SQLite 单文件，零外部数据库服务，备份就是拷文件。
- 对外只暴露 443，3000 绑 127.0.0.1 不直接暴露。

## 2. 服务器选型（川师学生规模）

| 项 | 建议 |
|---|---|
| CPU/内存 | 2 核 4G 起步，预算允许 4 核 8G |
| 带宽 | 5Mbps 起步，按需升 |
| 系统 | Ubuntu 22.04 LTS |
| 磁盘 | 40G SSD 起步 |
| 厂商 | 腾讯云/阿里云轻量应用服务器，约 ¥50-100/月，学生套餐更便宜 |
| 地域 | 成都（就近） |

结论：一台轻量云服务器即可，无需负载均衡、数据库服务、对象存储起步。

## 3. Node 版本要求

- 后端使用 Node 内置 `node:sqlite`，必须 Node 22.5+，建议 22.13+。
- 安装（Ubuntu）：

```bash
# 方式一：nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc
nvm install 22
node -v

# 方式二：apt
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
node -v
```

## 4. 依赖安装与首次启动

```bash
cd backend
npm install
node server.js
# 看到 listening on http://127.0.0.1:3000 即成功
curl http://127.0.0.1:3000/api/goods/list   # 应返回 {"code":0,...}
```

注意：`backend/.env` 不入库，服务器上手动创建（见 04 篇）；非 demo 档需先创建管理员账号 `node backend/tools/admin_user.js add --username <账号> --password <密码>`。

## 5. 进程守护（pm2 推荐）

```bash
sudo npm install -g pm2
cd backend
pm2 start server.js --name lingdong-backend
pm2 save && pm2 startup   # 开机自启
pm2 logs lingdong-backend # 看日志
pm2 reload lingdong-backend # 更新后秒级重启
pm2 status
```

或 systemd：

```ini
# /etc/systemd/system/lingdong.service
[Unit]
Description=Lingdong Backend
After=network.target
[Service]
WorkingDirectory=/opt/lingdong/backend
ExecStart=/usr/bin/node server.js
Restart=always
RestartSec=3
Environment=NODE_ENV=production
[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now lingdong
sudo journalctl -u lingdong -f
```

