# 07 · 上线操作手册（手把手）

最后更新：2026-09-26

> 从买服务器到小程序发布，每一步都写清楚打开哪个网站、登录后点哪里、填什么。厂商以腾讯云/阿里云为例，二选一即可。

## 第 1 步：注册云厂商账号

腾讯云：

1. 浏览器打开 https://cloud.tencent.com
2. 右上角点「免费注册」，用微信/QQ/手机号注册
3. 注册后打开 https://cloud.tencent.com/act/campus 学生优惠页，按提示做学生认证（学信网验证），可享低价套餐

阿里云：

1. 打开 https://www.aliyun.com
2. 右上角点「免费注册」
3. 学生优惠在 https://www.aliyun.com/activity/student 申请学生认证

## 第 2 步：购买轻量应用服务器

腾讯云：

1. 登录后进入「控制台」（右上角头像旁）
2. 顶部搜索框输入「轻量应用服务器」，点搜索结果进入
3. 点「新建」或「购买」
4. 地域选「成都」；镜像类型选「系统镜像」；镜像选「Ubuntu 22.04 LTS」
5. 套餐选 2核4G（预算宽裕选 4核8G）；流量包/带宽选 5Mbps；硬盘 40G
6. 设置 root 密码（记好）
7. 勾选协议 → 点「立即购买」→ 付款

阿里云：

1. 控制台顶部搜索「轻量应用服务器」，进入
2. 点「创建实例」→ 地域成都 → 镜像 Ubuntu 22.04 → 套餐 2核4G → 设置密码 → 创建并付款

## 第 3 步：注册域名

腾讯云：

1. 控制台顶部搜索「域名注册」，进入
2. 输入想好的域名（如 lingdong.cn）点「查询」，看是否可注册
3. 可注册则点「加入购物车」→ 去结算
4. 先完成「实名认证」（控制台 → 域名注册 → 信息模板，填身份证），再购买或购买后补
5. 付款完成

阿里云：控制台搜索「域名注册」→ 查询 → 购买 → 实名认证。建议与服务器同厂商，备案联动方便。

## 第 4 步：提交 ICP 备案（最耗时，立即办）

腾讯云：

1. 控制台顶部搜索「ICP 备案」，进入备案控制台
2. 点「开始备案」
3. 填主体信息：负责人姓名、身份证号、手机号（拍照上传身份证正反面）
4. 填网站信息：域名、网站名称（如"零栋校园无人送餐"）、网站用途选「其他-校园服务」、服务内容填写"校园无人送餐/快递配送服务"
5. 点「提交」，等待：云厂商初审 1-2 天 → 管局审核 2-4 周
6. 备案通过后获得备案号，短信/控制台通知

阿里云：控制台搜索「备案」→ 进入 ICP 备案 → 按引导填写，流程相同。

备案等待期不用干等：继续做第 5~10 步，用 IP 直连测试；备案号下来再切域名。

## 第 5 步：登录服务器（SSH）

腾讯云：

1. 控制台 → 轻量应用服务器 → 实例列表
2. 点实例右侧「登录」按钮 → 网页终端，直接进入命令行
3. 或本机打开终端/命令提示符，输入 `ssh root@<服务器公网IP>`，输入第 2 步设的密码

验证：输入 `node -v`（先确认有没有 Node，没有就做第 6 步）。

## 第 6 步：安装 Node 22

在服务器命令行逐行输入：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc
nvm install 22
node -v    # 应显示 v22.x
```

## 第 7 步：部署后端代码

```bash
sudo apt update
cd /opt
sudo git clone https://github.com/VesselPaper/lingdong-delivery-miniprogram.git lingdong
cd /opt/lingdong/backend
sudo npm install
```

再创建生产配置和启动：

1. 在 /opt/lingdong/backend 下创建 .env 文件（内容见 04 篇），填真实凭据
2. 创建管理员账号：`sudo node tools/admin_user.js add --username admin --password <密码>`
3. 启动：`sudo node server.js`，看到 listening on 127.0.0.1:3000 即成功
4. 安装 pm2 守护：`sudo npm install -g pm2 && sudo pm2 start server.js --name lingdong-backend && sudo pm2 save`

## 第 8 步：域名解析（备案号下来后做）

腾讯云：

1. 控制台顶部搜索「DNS 解析 DNSPod」，进入
2. 点「添加域名」，输入你的域名（如 lingdong.cn）
3. 进入域名解析列表，点「添加记录」：
   - 记录类型 A，主机记录 api，记录值 服务器公网IP
   - 记录类型 A，主机记录 @，记录值 服务器公网IP
4. 保存。等几分钟生效（命令行 `ping api.lingdong.cn` 能看到 IP 即生效）

## 第 9 步：Nginx + HTTPS 证书

服务器命令行：

```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

创建站点配置（内容见 02 篇 §5.2），然后：

```bash
sudo ln -s /etc/nginx/sites-available/lingdong /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d api.lingdong.cn    # 自动申请证书并续期
```

注意：certbot 这步必须等备案号下来、域名解析生效后才能成功。

## 第 10 步：小程序后台配合法域名

1. 浏览器打开 https://mp.weixin.qq.com，用小程序管理员微信扫码登录（用户端零栋GO 和商家端各登一次）
2. 左侧菜单「开发」→「开发管理」→「开发设置」
3. 拉到「服务器域名」→ 点「修改」：
   - request 合法域名：填 https://api.lingdong.cn
   - uploadFile 合法域名：填 https://api.lingdong.cn
   - downloadFile 合法域名：填 https://api.lingdong.cn 和 https://eventec-k8s-pro.oss-cn-beijing.aliyuncs.com
   - socket 合法域名：填 wss://api.lingdong.cn
4. 分别点「保存」

## 第 11 步：微信支付商户号（要真实收款才做）

1. 打开 https://pay.weixin.qq.com
2. 点「成为商家」→ 注册商户号，按引导提交营业执照/主体信息（主体必须与企业/个体一致）
3. 通过后：管理后台 → API安全 → 申请 API 证书、设置 APIv3 密钥，把四要素交给后端配置（04 篇）

未办好之前，可用 pilot + PAY_MOCK 过渡上线。

## 第 12 步：小程序上传与发布

1. 微信开发者工具打开项目（用户端/商家端）
2. 把 utils/config.js 的 CURRENT 改为 'prod'
3. 右上角点「上传」→ 填版本号（如 1.0.0）和备注 → 确定
4. 回 https://mp.weixin.qq.com → 「管理」→「版本管理」→ 看到刚上传的版本
5. 点「选为体验版」→ 生成二维码 → 发给体验成员扫码测试
6. 测试通过 → 点「提交审核」→ 填功能页面说明 → 等审核（几小时~1-2天）
7. 审核通过 → 点「发布」（可先分阶段发布灰度）

## 上线后

- 每日备份：按 05 篇配置 cron
- 改 bug：按 06 篇流程（体验版免审复测）
