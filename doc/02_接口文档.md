# 02 · 接口文档（API）

最后更新：2026-09-03
说明：自建后端（Node/Express/SQLite）全部接口。开放物流平台（robox）36 个外部接口见 项目进度/03_技术记录.md 与 文档/飞书文档。
后端地址：http://127.0.0.1:3000（生产替换为正式域名）；前端请求统一走 utils/request.js。

## 通用约定

### Base URL
开发：`http://localhost:3000/api` 或 `http://127.0.0.1:3000/api`
生产：由小程序 config.js 的 baseUrl 配置，需为小程序后台白名单域名（https）。

### 请求格式
Content-Type: application/json；请求体为 JSON。

### 返回结构（统一）
```json
{ "code": 0, "msg": "success", "data": { ... } }
```
- code = 0 表示成功；非 0 为业务失败或 HTTP 状态码。
- HTTP 状态码与业务 code 通常一致：400 参数/状态错误、401 未登录、403 无权限、404 不存在、500 服务端、501 未配置、502 上游失败。

### 鉴权
除登录、商品、点位、活动、平台回调外，均需在请求头携带：
```
Authorization: Bearer <token>
```
token 即登录返回的 openid（演示模式下为 demo_ 前缀的稳定哈希）。登录失效返回 401。

### 登录
POST /api/auth/login 返回 token 与 user，前端存 storage（key: token / userInfo）。

### 文件上传
POST /api/merchant/upload，body 传 base64 图片数据，返回 /uploads/xxx 相对路径；前端 request.js 会自动转成完整地址。

### 分页
当前接口均为全量返回（无分页）；如后续数据量大，订单/商品列表可加 page/size。

### 错误码速查
- 0 成功
- 400 参数错误 / 业务状态不允许
- 401 未登录 / 登录失效
- 403 无权限（非商家访问商家接口）
- 404 数据不存在
- 500 服务端异常
- 501 功能未开通（支付通道未配置）
- 502 上游调用失败（微信下单失败、获取机器人失败）

## 一、用户与鉴权

### 1.1 登录
- 地址：POST /api/auth/login
- 鉴权：无
- 入参：
```json
{ "code": "wx.login 返回的 code", "role": "student | merchant", "nickname": "昵称(可选)" }
```
- 出参：
```json
{ "token": "openid", "user": { "id":1, "openid":"...", "nickname":"...", "phone":"...", "role":"student" } }
```
- 说明：测试阶段为演示登录（以 code 稳定哈希为 openid，点击微信登录直接成功）；正式环境启用 code2session（server.js 中注释保留，配置 WX_APPID/WX_SECRET 后启用）。
- 错误：400 缺少登录凭证。

### 1.2 获取用户信息
- 地址：GET /api/user/profile
- 鉴权：需登录
- 出参：user 对象（id/openid/nickname/phone/role）

### 1.3 更新用户信息
- 地址：PUT /api/user/profile
- 鉴权：需登录
- 入参：`{ "nickname": "新昵称", "phone": "13800000000" }`（均可选）
- 出参：更新后的 user

## 二、商品

### 2.1 商品分类
- 地址：GET /api/goods/categories
- 出参：`["热卤","卤味","饮品","套餐"]`

### 2.2 商品列表
- 地址：GET /api/goods/list
- Query：`category=热卤`（可选）、`keyword=xxx`（可选，名称模糊）
- 出参：goods 数组（仅 status=1 在售，按销量排序）
```json
[{ "id":1, "name":"...", "price":10.9, "original_price":12.9, "image":"", "category":"热卤", "stock":100, "status":1, "description":"...", "sales":326 }]
```

### 2.3 商品详情
- 地址：GET /api/goods/detail?id=1
- 出参：单个 goods；404 商品不存在

## 三、点位

### 3.1 点位列表
- 地址：GET /api/landmarks
- 出参：
```json
[{ "id":1, "name":"零栋铺子（取餐点）", "building":"零栋", "floor":"1F", "type":"loadingPoint", "sort":1,
   "platform_building_id":"", "platform_map_id":"", "platform_landmark_id":"" }]
```
- 说明：type 取 loadingPoint（上货点）/ deliverPoint（配送点）；platform_* 为真实平台点位映射（同步后才有值）。

## 四、购物车

### 4.1 购物车列表
- 地址：GET /api/cart/list
- 鉴权：需登录
- 出参：
```json
[{ "id":1, "goods_id":1, "quantity":2, "selected":1, "name":"...", "price":10.9, "image":"", "goods_status":1 }]
```

### 4.2 加入购物车
- 地址：POST /api/cart/add
- 入参：`{ "goods_id":1, "quantity":1 }`
- 说明：已存在则累加数量。

### 4.3 更新购物车
- 地址：PUT /api/cart/update
- 入参：`{ "id":1, "quantity":2, "selected":0 }`（quantity/selected 均可选）

### 4.4 删除购物车项
- 地址：DELETE /api/cart/remove
- 入参：`{ "id":1 }`

## 五、收货地址

### 5.1 地址列表
- 地址：GET /api/address/list
- 鉴权：需登录
- 出参：默认地址排最前
```json
[{ "id":1, "contact_name":"张三", "contact_phone":"13800000000", "landmark_id":"2", "landmark_name":"东苑 3 栋", "detail":"3-201", "is_default":1 }]
```

### 5.2 保存/新增/编辑地址
- 地址：POST /api/address/save
- 鉴权：需登录
- 入参：`{ "id":可选(编辑时传), "contact_name":"张三", "contact_phone":"138...", "landmark_id":"2", "landmark_name":"东苑 3 栋", "detail":"3-201", "is_default":1 }`
- 说明：landmark_id 后端统一转字符串存储；传 is_default=1 时自动清除其它默认。

### 5.3 删除地址
- 地址：DELETE /api/address/delete
- 鉴权：需登录
- 入参：`{ "id":1 }`

## 六、订单

订单状态：0 待支付 / 1 待接单 / 2 配送中 / 3 已送达 / 4 已完成 / 5 已取消 / 6 配送异常

### 6.1 创建订单
- 地址：POST /api/order/create
- 鉴权：需登录
- 入参：
```json
{ "landmark_id":"2", "landmark_name":"东苑 3 栋", "remark":"不要辣", "items":[{"goods_id":1,"quantity":2}] }
```
- 出参：`{ "order_id":7, "order_no":"LD12345678XXXX", "total_amount":21.8, "pickup_code":"1234" }`
- 说明：后端按商品表单价计价；生成 order_no 与 4 位取餐码；扣库存、加销量、清空购物车。
- 错误：400 订单不能为空 / 商品不存在。

### 6.2 支付下单（微信支付 V3 JSAPI）
- 地址：POST /api/order/pay
- 鉴权：需登录
- 入参：`{ "id":7 }`
- 出参：`{ "order_id":7, "payParams": { "timeStamp":"", "nonceStr":"", "package":"prepay_id=...", "signType":"RSA", "paySign":"..." } }`
- 说明：前端拿到 payParams 调 wx.requestPayment；支付结果以微信回调为准。
- 错误：400 状态不允许支付 / 404 订单不存在 / 501 支付通道未配置 / 502 微信下单失败。

### 6.3 微信支付结果回调（微信服务器调用）
- 地址：POST /api/pay/notify
- 鉴权：无（微信服务器直调，需公网可达 https）
- 入参：微信支付 V3 回调报文（resource 加密）
- 出参：`{ "code":"SUCCESS", "message":"成功" }`
- 说明：解密 resource，trade_state=SUCCESS 且订单待支付时置 status=1。

### 6.4 订单列表
- 地址：GET /api/order/list?status=1
- 鉴权：需登录
- Query：status 可选（空=全部）
- 出参：orders 数组（含 status_text）

### 6.5 订单详情
- 地址：GET /api/order/detail?id=7
- 鉴权：需登录
- 出参：
```json
{ "...订单字段...", "status_text":"配送中", "items":[{ "goods_id":1,"goods_name":"...","quantity":2,"price":10.9 }],
  "task": { "task_status":50, "status_text":"已上货，出发配送" } }
```

### 6.6 取消订单
- 地址：POST /api/order/cancel
- 鉴权：需登录
- 入参：`{ "id":7 }`
- 说明：仅待支付(0)/待接单(1)可取消，取消后状态 5。
- 错误：400 配送中的订单无法取消。

## 七、配送

### 7.1 配送追踪
- 地址：GET /api/delivery/track?order_id=7
- 鉴权：需登录
- 出参：
```json
{ "order_status":3, "order_status_text":"已送达", "pickup_code":"1234", "landmark_name":"东苑 3 栋",
  "task": { "task_status":70, "status_text":"已到达取餐点" },
  "position": { "x":996,"y":880,"theta":-3.117,"timestamp":..., "locQuality":"100.0" } }
```
- 说明：position 真实模式来自平台 eviz（可能为 null），Mock 模式返回模拟坐标。

### 7.2 确认取餐
- 地址：POST /api/delivery/confirm
- 鉴权：需登录
- 入参：`{ "order_id":7, "scan_code":"1234" }`
- 说明：须订单已送达(3)；传 scan_code 时与 pickup_code 比对。
- 错误：400 机器人还未送达 / 取餐码不匹配。

## 九、商家端（全部需商家身份，403 无权限）

### 9.1 店铺状态
- 地址：GET /api/merchant/shop
- 出参：`{ "id":1, "name":"零栋铺子", "business_status":"open", "auto_accept":0 }`

### 9.2 更新店铺状态
- 地址：PUT /api/merchant/shop
- 入参：`{ "business_status":"open|closed", "auto_accept":1 }`
- 出参：更新后 shop

### 9.3 工作台统计
- 地址：GET /api/merchant/stats
- 出参：`{ "today_orders":10, "today_amount":120.5, "pending":2, "delivering":1, "finished":3 }`

### 9.4 商家订单列表
- 地址：GET /api/merchant/orders?status=1
- 出参：全部订单（可带 status 过滤），含 status_text

### 9.5 商家订单详情
- 地址：GET /api/merchant/order/detail?id=7
- 出参：订单 + items

### 9.6 商家接单（创建配送任务）
- 地址：POST /api/merchant/order/confirm
- 入参：`{ "id":7 }`
- 出参：`{ "order_id":7, "status":2 }`
- 说明：校验店铺营业（歇业拒绝）、订单状态须为 1；调用平台层创建配送任务（真实模式 queue/create，Mock 模式本地状态机）。
- 错误：400 店铺歇业中 / 订单状态不允许接单。

### 9.7 图片上传
- 地址：POST /api/merchant/upload
- 入参：`{ "name":"img.jpg", "data":"<base64>" }`
- 出参：`{ "url":"/uploads/xxx.jpg" }`
- 说明：仅 jpg/jpeg/png/webp/gif；返回相对路径。

### 9.8 商品列表（含下架）
- 地址：GET /api/merchant/goods
- 出参：全部 goods

### 9.9 新增商品
- 地址：POST /api/merchant/goods
- 入参：`{ "name":"...", "price":10.9, "original_price":12.9, "image":"", "category":"热卤", "stock":100, "description":"..." }`
- 出参：`{ "id":11 }`

### 9.10 编辑商品
- 地址：PUT /api/merchant/goods
- 入参：`{ "id":11, "name":"...", "price":..., "status":1, ... }`

### 9.11 商品上下架
- 地址：PUT /api/merchant/goods/status
- 入参：`{ "id":11, "status":0 }`（1 在售 / 0 下架）

### 9.12 配送监控
- 地址：GET /api/merchant/delivery/monitor
- 出参：未完成配送任务数组（含 order_no、landmark_name、order_status、task_status、status_text、position）

### 9.13 机器人设备列表
- 地址：GET /api/merchant/robots
- 出参：真实机器人数组（平台 runtimeStatusList）
```json
[{ "device_sn":"...", "name":"...", "type":"SendBot", "online":true, "online_text":"在线",
   "battery":100, "machine_status":"charging", "machine_text":"充电中", "floor":"1", "building":"...", "version":"V3.6.1" }]
```
- 错误：502 本地演示模式 / 未配置开放物流平台凭据 / 获取机器人失败。

### 9.14 活动列表（含未发布）
- 地址：GET /api/merchant/activities

### 9.15 新建活动
- 地址：POST /api/merchant/activities
- 入参：`{ "title":"...", "subtitle":"", "image":"", "link":"", "sort":0 }`（保存后默认发布 status=1）
- 出参：`{ "id":1 }`

### 9.16 编辑活动
- 地址：PUT /api/merchant/activities
- 入参：`{ "id":1, "title":"...", "subtitle":"", "link":"", "sort":0 }`

### 9.17 活动上下线
- 地址：PUT /api/merchant/activities/status
- 入参：`{ "id":1, "status":0 }`（1 发布 / 0 下线）

### 9.18 删除活动
- 地址：DELETE /api/merchant/activities
- 入参：`{ "id":1 }`

### 9.19 平台点位同步
- 地址：POST /api/merchant/landmarks/sync
- 出参：`{ "ok":true, "buildingId":"...", "count":n, "updated":n }`
- 说明：调平台 buildingList + landmarkInfo 写入 landmarks 表 platform_* 字段。
- 错误：500 未配置平台凭据 / 同步失败。

## 十、开放物流平台回调（平台方调用）

### 10.1 配送任务状态回调（feedbackDeliveryTaskUrl）
- 地址：POST /api/platform/callback/delivery
- 鉴权：无（平台调用，需公网可达 https）
- 入参（平台回调结构，兼容多种字段）：
```json
{ "taskId":"...", "taskStatus":70, "taskStatusText":"已到达取餐点", "deviceSn":"..." }
```
- 出参：`{ "code":"SUCCESS", "msg":"ok" }`
- 说明：按 platform_task_id 找到本地任务，applyStatus 联动订单状态。

### 10.2 业务订单支付校验（checkBizOrderStatusUrl）
- 地址：GET /api/platform/check-order?orderNo=LD12345678XXXX
- 出参：`{ "code":"COMM_200", "msg":"已支付", "data":{ "paid":true } }`
- 说明：平台下发任务前校验订单是否已支付（status>0）。

### 10.3 设备异常上报回调
- 地址：POST /api/platform/callback/exception
- 出参：`{ "code":"SUCCESS", "msg":"ok" }`
- 说明：T 任务类 / R 机器类 / I IOT 类 / N 导航类异常，当前仅记录日志。

## 十一、状态同步机制（真实模式）

- 主通道：平台 feedbackDeliveryTaskUrl 回调推送任务状态。
- 兜底：后端每 PLATFORM_POLL_MS（默认 8s）轮询 deliveryTask/basicList 同步活动任务。
- 位置：配送追踪/监控调 eviz（iotGatewayProxy）获取机器人坐标，3 秒缓存。
