# 06 · 接口与数据协议 · 01 用户与商品接口

### 2.1 user 域（`domains/user/routes.js`）：登录 / 资料 / 楼栋 / 购物车 / 地址 / 红点

| 方法 | 路径 | 鉴权 | 说明 | 关键出入参 |
| --- | --- | --- | --- | --- |
| POST | `/auth/login` | 无 | 登录（用户/商家），`service.login` | 入 `{code, nickname?, merchant_code?, client?}`；出 `{token, user, runtime}` |
| GET | `/user/profile` | 用户 | 当前用户信息（`auth` 直出 `req.user`） | 出：user 对象 |
| PUT | `/user/profile` | 用户 | 更新昵称/手机号/头像，`queries.updateProfile` | 入 `{nickname?, phone?, avatar?}`；出：更新后 user |
| POST | `/user/avatar` | 用户 | 头像上传（base64，≤2MB，jpg/png/webp），成功即写库 | 入 `{name?, data}`；出：更新后 user；自动删除本人旧头像 |
| GET | `/user/point` | 用户 | 当前配送楼栋（首页/我的/结算三处共用） | 出 `{landmark_id, landmark_name}` |
| PUT | `/user/point` | 用户 | 设置配送楼栋（须命中 deliverPoint 点位） | 入 `{landmark_id}`；出同上 |
| GET | `/cart/list` | 用户 | 购物车列表（附实时库存与折后价 `price_now`），`service.cartListWithPrice` | 出：cart 数组 |
| POST | `/cart/add` | 用户 | 加入购物车（已存在则累加数量） | 入 `{goods_id, quantity=1}` |
| PUT | `/cart/update` | 用户 | 改数量/勾选 | 入 `{id, quantity?, selected?}` |
| DELETE | `/cart/remove` | 用户 | 删除购物车项 | 入 `{id}` |
| GET | `/address/list` | 用户 | 地址列表（默认排前） | 出：address 数组（`landmark_id` 为字符串） |
| POST | `/address/save` | 用户 | 新增/编辑地址；`is_default=1` 自动清其它默认并同步当前楼栋 | 入 `{id?, contact_name, contact_phone, landmark_id, landmark_name, detail, is_default?}` |
| DELETE | `/address/delete` | 用户 | 删除地址 | 入 `{id}` |

红点接口（定义于 order 域，见 2.3）：`GET /user/order/badge`、`POST /user/order/mark-read`。

### 2.2 goods 域（`domains/goods/routes.js`）：商品 / 活动 / 店铺状态（公开）与商家商品·活动管理

| 方法 | 路径 | 鉴权 | 说明 | 关键出入参 |
| --- | --- | --- | --- | --- |
| GET | `/goods/categories` | 无 | 商品分类列表，`queries.categories` | 出：`["热卤","卤味",…]` |
| GET | `/goods/list` | 无 | 商品列表（仅 status=1 在售，按销量排序；附 `sale_price`/`discount_info` 展示价），`queries.list + service.withPromoPrices` | Query `category?`、`keyword?`；出：goods 数组 |
| GET | `/goods/detail` | 无 | 商品详情 | Query `id`；404 商品不存在 |
| GET | `/activity/list` | 无 | 已发布活动（含 type/config/起止时间/state），`service.listActivitiesTyped` | 出：活动数组 |
| GET | `/shop/status` | 无 | 店铺营业状态（用户端展示歇业/禁单） | 出 `{id, name, business_status, auto_accept, delivery_fee}` |
| GET | `/merchant/shop` | 商家 | 店铺信息（商家端） | 出：同 shop/status |
| PUT | `/merchant/shop` | 商家 | 更新店铺（未传字段保留原值；配送费 0~999 元） | 入 `{business_status?, auto_accept?, delivery_fee?}`；出：更新后 shop |
| POST | `/merchant/upload` | 商家 | 图片上传（base64，jpg/jpeg/png/webp/gif） | 入 `{name?, data}`；出 `{url:"/uploads/xx.jpg"}` |
| GET | `/merchant/goods` | 商家 | 商品管理列表（含下架、实时库存/销量） | 出：全部 goods |
| GET | `/merchant/goods/categories` | 商家 | 分类选择器数据（按首次出现顺序） | 出：分类数组 |
| PUT | `/merchant/goods/stock` | 商家 | 单独调库存（置 0=售罄；恢复传正数），`queries.updateStock` | 入 `{id, stock}`；出：更新后商品 |
| POST | `/merchant/goods` | 商家 | 新增商品（stock 缺省 99），`queries.insert` | 出 `{id}` |
| PUT | `/merchant/goods` | 商家 | 编辑商品（未传 stock 保留原库存），`queries.update` | 入 `{id, …}` |
| PUT | `/merchant/goods/status` | 商家 | 上下架（1 在售 / 0 下架） | 入 `{id, status}` |
| GET | `/merchant/activities` | 商家 | 活动列表（含未发布） | 出：活动数组 |
| POST | `/merchant/activities` | 商家 | 新建活动（默认发布），`queries.insertActivity` | 入 `{title, subtitle?, image?, link?, sort?, type?, config?, start_at?, end_at?}`；出 `{id}` |
| PUT | `/merchant/activities` | 商家 | 编辑活动 | 入 `{id, …}` |
| PUT | `/merchant/activities/status` | 商家 | 活动上下线（1 发布 / 0 下线） | 入 `{id, status}` |
| DELETE | `/merchant/activities` | 商家 | 删除活动 | 入 `{id}` |
