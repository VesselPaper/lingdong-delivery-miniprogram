# 06 · 接口与数据协议 · 05 管理域与大屏接口

### 2.6 admin 域（`domains/admin/routes.js`）：管理员登录 / me / 登出 / 改密 / 管理操作

> 鉴权统一为**管理员**（`x-admin-token`，否则 401）；`/dashboard/*` 与 `/config/tianditu` 免登录（见 2.7）。

| 方法 | 路径 | 说明 | 关键出入参 |
| --- | --- | --- | --- |
| POST | `/admin/login` | 管理员登录（用户名+密码→session token；账号+IP 失败限流 `ADMIN_LOGIN_MAX=5` 次/10 分钟） | 入 `{username, password}`；出 `{token, admin}` |
| GET | `/admin/me` | 当前登录管理员（前端启动校验会话） | 出 `{admin}` |
| POST | `/admin/logout` | 登出（吊销当前 session），`adminAuth.revokeSession` | |
| POST | `/admin/password` | 修改密码（≥8 位；改后吊销全部会话） | 入 `{old_password, new_password}` |
| GET | `/admin/verify` | 令牌校验（对=200） | 出 `{valid:true, admin:true}` |
| GET | `/admin/state` | 状态总览（设备/平台任务/本地批次订单任务/死锁异常检测），`service.buildAdminState` | 出 `{robot, platform_tasks, batches, orders, tasks, alerts}` |
| GET | `/admin/batch/orders` | 批次内订单全量（展开懒加载） | Query `batch_id` |
| GET | `/admin/map` | 管理端地图（3s 缓存） | 出：地图聚合 |
| GET | `/admin/radar` | 机器人实时雷达数据（激光点云/代价地图/位姿） | Query `device_sn` |
| POST | `/admin/summon` | 召唤机器人到上货点 | 入 `{device_sn}` |
| POST | `/admin/robot/summon` | 召唤到指定点位（含充电点；中断当前任务） | 入 `{device_sn, landmark_id}` |
| GET | `/admin/robot/summon-targets` | 召唤可选目标点列表 | 出：目标点数组 |
| POST | `/admin/robot/stop` | 机器人驻停（stop_time 秒后恢复） | 入 `{device_sn, stop_time=30}` |
| POST | `/admin/robot/recover` | 机器人继续工作 | 入 `{device_sn}` |
| POST | `/admin/robot/stop-cancel` | 停止并取消正在做的任务 | 入 `{device_sn}` |
| POST | `/admin/task/cancel` | 取消排队任务（status<10） | 入 `{platform_task_id}` |
| POST | `/admin/task/close` | 关闭任务（舱内有货自动开舱） | 入 `{device_sn, platform_task_id}` |
| POST | `/admin/task/void` | 本地作废任务（置 110+void_at） | 入 `{task_id}` |
| POST | `/admin/task/close-void` | 关闭平台任务+本地作废（一键） | 入 `{task_id}` |
| POST | `/admin/precreate/del` | 删除预创建任务（立即关舱） | 入 `{device_sn}` |
| POST | `/admin/drawer` | 独立开/关舱门（不影响任务状态） | 入 `{device_sn, cmd=1}` |
| POST | `/admin/control/grant` | 获取设备控制权（600s） | 入 `{device_sn}` |
| POST | `/admin/control/release` | 释放设备控制权 | 入 `{device_sn, ctrl_id}` |
| POST | `/admin/order/cancel` | 本地取消订单（作废任务+回补库存+摘批次+平台召回） | 入 `{order_id}`；出 `{claimed, final_status, tasks}` |
| POST | `/admin/batch/cancel` | 清理批次（取消批内活跃订单+释放控制权+批次置4） | 入 `{batch_id}` |
| POST | `/admin/orders/bulk-cancel` | 批量删除订单（逐单容错） | 入 `{order_ids:[…]}` |
| POST | `/admin/batches/bulk-cancel` | 批量清理批次 | 入 `{batch_ids:[…]}` |
| POST | `/admin/tasks/bulk-close-void` | 批量关闭+作废任务 | 入 `{task_ids:[…]}` |
| POST | `/admin/landmarks/sync` | 平台点位同步 | 出 `{ok, count, …}` |
| POST | `/admin/reset` | 一键初始化（关全部平台任务+释放控制权+取消活跃订单+批次置4；危险操作需二次确认） | 出 `{closed, released, cancelled, batch_cleaned, failed}` |

### 2.7 dashboard（只读聚合，免登录）

| 方法 | 路径 | 说明 | 关键出入参 |
| --- | --- | --- | --- |
| GET | `/dashboard/overview` | 大屏只读聚合（5s 缓存），`service.buildDashboard` | 出 `{server_time, run_mode, real_platform, shop, stats, map, map_error, robots, robots_error, batches, pickup_alerts}` |
| GET | `/dashboard/map-image` | 地图底图字节（同源代理，10 分钟缓存） | 出：image/png 字节流 |
| GET | `/config/tianditu` | 天地图浏览器端 tk 配置（从 .env 注入） | 出 `{tk, ts}` |

### 2.8 公开（shop/status 等）

免鉴权接口完整清单见 1.4 节。其中与业务直接相关且用户端高频使用的：

- `GET /api/shop/status` —— 店铺营业状态：用户端据此展示「歇业」标签、结算按钮置灰；
  后端 `POST /api/order/create` 在店铺 `business_status=closed` 时兜底拒绝（400「店铺歇业中，暂无法下单」）。
- `GET /api/goods/*`、`GET /api/activity/list`、`GET /api/landmarks` —— 用户端商城与点位选择。
- `GET /api/dashboard/*` —— 大屏展示（只读，无写权限）。
