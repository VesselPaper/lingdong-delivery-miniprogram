# 06 · 接口与数据协议 · 02 订单接口

### 2.3 order 域（`domains/order/routes.js`）：下单 / 支付 / 列表 / 取消 / 申请 / 售后 / 商家订单

| 方法 | 路径 | 鉴权 | 说明 | 关键出入参 |
| --- | --- | --- | --- | --- |
| POST | `/order/create` | 用户 | 创建订单（详见 3.2），`service.createOrder` | 入 `{landmark_id, landmark_name, contact_name, contact_phone, remark?, items:[{goods_id,quantity}], activity_id?, address_id?}`；出 `{order_id, order_no, total_amount, pickup_code}`（超 12 件自动拆单时出 `{orders:[…], split:true}`） |
| POST | `/order/pay` | 用户 | 发起支付（详见 3.3），`service.payOrder` | 入 `{id}`；出 `{order_id, payParams}` 或 `{mock:true}` |
| POST | `/pay/notify` | 无 | 微信支付 V3 回调（验签/幂等/金额比对后置已支付） | 出 `{code:"SUCCESS"}` |
| GET | `/order/list` | 用户 | 我的订单列表（附 `status_text`/`code_short`） | Query `status?`（空=全部） |
| GET | `/order/detail` | 用户 | 订单详情（附 items/task/batch/cancel_request/free_cancel_left_ms/可取消标记） | Query `id` |
| GET | `/user/order/badge` | 用户 | 我的页红点：进行中订单常驻计数，`queries.badgeCounts` | 出 `{unread, count, has_active, paying, delivering, arrived, finished}` |
| POST | `/user/order/mark-read` | 用户 | 标记已读（兼容保留，不再清除红点） | 入：空 |
| POST | `/order/cancel` | 用户 | 取消订单（免费窗口内；CAS 抢占），`service.applyOrderCancelled` | 入 `{id}`；出 `{order_id, status:5}` |
| POST | `/order/cancel-request` | 用户 | 提交取消申请（超窗口且未配送时） | 入 `{order_id, reason}`；出 `{id, status:0}` |
| GET | `/order/cancel-request/list` | 用户 | 我的取消申请记录 | 出：申请数组 |
| GET | `/merchant/cancel-requests` | 商家 | 取消申请列表 | Query `status?`；待处理优先 |
| GET | `/merchant/cancel-request/detail` | 商家 | 取消申请详情（含订单信息） | Query `id` |
| POST | `/merchant/cancel-request/handle` | 商家 | 处理取消申请：approve（订单→5）/ reject（需理由） | 入 `{id, action, reply?}` |
| POST | `/refund/apply` | 用户 | 申请退款/投诉（仅 3/4/6 或卡死配送中可申请；一单一笔待处理） | 入 `{order_id, type, reason}`；出 `{id, type, status:0}` |
| GET | `/refund/list` | 用户 | 我的售后记录 | 出：售后数组 |
| GET | `/merchant/refunds` | 商家 | 商家售后列表 | Query `status?` |
| GET | `/merchant/refund/detail` | 商家 | 售后详情（含订单信息） | Query `id` |
| POST | `/merchant/refund/handle` | 商家 | 处理售后：退款 approve（可改金额）/ reject（需理由）；投诉 reply | 入 `{id, action, amount?, reply?}`；退款走 `service.realRefundOrLocal` |
| GET | `/merchant/stats` | 商家 | 工作台统计，`service.computeStats` | 出 `{today_orders, today_amount, pending, ready_load, delivering, pickup, exception, aftersale, cancel_requests, finished}` |
| GET | `/merchant/orders` | 商家 | 商家订单列表（status / scope=active\|history / stage=accept\|load\|deliver\|pickup 三选一过滤；含 items/first_*/batch 摘要、手机号脱敏） | 出：订单数组 |
| GET | `/merchant/order/detail` | 商家 | 商家订单详情（含 daily_seq/items/batch） | Query `id` |
| POST | `/merchant/order/confirm` | 商家 | 接单并入配送批次（歇业拒绝），`batch.addOrderToBatch` | 入 `{id}`；出 `{order_id, status:2, batch_id, batch_no, msg}` |
| POST | `/merchant/order/exception/retry` | 商家 | 配送异常重配（详见 3.11） | 入 `{order_id}`；出 `{order_id, status:2, batch_id, batch_no, msg}` |
| POST | `/merchant/order/exception/refund` | 商家 | 配送异常取消并退款（订单→7，自动写售后记录） | 入 `{order_id}`；出 `{order_id, status:7, msg}` |
| GET | `/merchant/orders/exception` | 商家 | 异常订单列表 | Query `tab=all\|pending\|done`；每单含 `handled`/`handled_text` |
