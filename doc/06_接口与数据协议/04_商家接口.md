# 06 · 接口与数据协议 · 04 商家接口

### 2.5 merchant（商家端，跨域聚合）

> 商家接口分散于 goods / order / delivery 三个域文件，此处按业务聚合；鉴权统一为**商家**（Bearer + role=merchant，否则 403）。

#### 2.5.1 工作台与订单

| 方法 | 路径 | 说明 | 关键出入参 |
| --- | --- | --- | --- |
| GET | `/merchant/stats` | 工作台统计（见 2.3） | 出 `{today_orders, today_amount, pending, ready_load, delivering, pickup, exception, aftersale, cancel_requests, finished}` |
| GET | `/merchant/orders` | 订单列表（stage/scope/status 过滤） | 出：订单数组（items/first_*/batch/`stage_text`） |
| GET | `/merchant/order/detail` | 订单详情 | Query `id` |
| POST | `/merchant/order/confirm` | 接单并入批次（一车多单） | 入 `{id}`；出 `{batch_id, batch_no, msg}` |
| POST | `/merchant/order/exception/retry` | 异常重配 | 入 `{order_id}` |
| POST | `/merchant/order/exception/refund` | 异常退款 | 入 `{order_id}` |
| GET | `/merchant/orders/exception` | 异常订单列表 | Query `tab` |
| GET | `/merchant/cancel-requests` | 取消申请列表 | Query `status?` |
| GET | `/merchant/cancel-request/detail` | 取消申请详情 | Query `id` |
| POST | `/merchant/cancel-request/handle` | 处理取消申请 | 入 `{id, action, reply?}` |
| GET | `/merchant/refunds` | 售后列表 | Query `status?` |
| GET | `/merchant/refund/detail` | 售后详情 | Query `id` |
| POST | `/merchant/refund/handle` | 处理售后 | 入 `{id, action, amount?, reply?}` |

#### 2.5.2 商品与活动

| 方法 | 路径 | 说明 | 关键出入参 |
| --- | --- | --- | --- |
| GET | `/merchant/shop` / PUT `/merchant/shop` | 店铺信息 / 更新（营业状态、自动接单、配送费） | 入 `{business_status?, auto_accept?, delivery_fee?}` |
| POST | `/merchant/upload` | 图片上传（base64） | 入 `{name?, data}`；出 `{url}` |
| GET | `/merchant/goods` | 商品列表（含下架） | 出：goods 数组 |
| GET | `/merchant/goods/categories` | 分类列表 | 出：分类数组 |
| POST/PUT | `/merchant/goods` | 新增 / 编辑商品 | 入 `{name, price, …, stock?}` |
| PUT | `/merchant/goods/stock` | 单独调库存（置 0=售罄） | 入 `{id, stock}` |
| PUT | `/merchant/goods/status` | 上下架 | 入 `{id, status}` |
| GET/POST/PUT/DELETE | `/merchant/activities` | 活动 CRUD | 入 `{title, …, type?, config?, start_at?, end_at?}` |
| PUT | `/merchant/activities/status` | 活动上下线 | 入 `{id, status}` |

#### 2.5.3 设备与配送（批次 / 扫码上货 / 配送监控）

| 方法 | 路径 | 说明 | 关键出入参 |
| --- | --- | --- | --- |
| GET | `/merchant/device/pending` | 组单/待上货/配送中批次（配单页） | 出 `{open_batches, ready_batches, active_batches, pending_orders}` |
| POST | `/merchant/device/scan` | 扫码识别机器人→定位批次 | 入 `{deviceSn}` |
| POST | `/merchant/device/batch/open-bin` | 批次开舱（整批上货验证） | 入 `{batch_id}` |
| POST | `/merchant/device/batch/close-bin` | 批次关舱（等待不派发） | 入 `{batch_id}` |
| POST | `/merchant/device/batch/dispatch` | 批次开始配送（立即配送） | 入 `{batch_id}` |
| POST | `/merchant/device/batch/mock-dispatch` | 模拟开始配送（测试档） | 入 `{batch_id}` |
| POST | `/merchant/device/open-bin` / `close-bin` / `dispatch` | 单任务开舱/关舱/派发（逐单形态，兼容保留） | 入 任务定位参数 |
| GET | `/merchant/delivery/batch/list` | 批次列表 | 出：近 20 批次 |
| GET | `/merchant/delivery/batch/detail` | 批次详情 | Query `batch_id` |
| POST | `/merchant/delivery/batch/dispatch` | 批次派车 | 入 `{batch_id, device_sn?}` |
| GET | `/merchant/robots` | 机器人设备列表 | 出：robots 数组 |
| GET | `/merchant/delivery/monitor` | 配送监控（任务维度） | 出：任务+position |
| GET | `/merchant/map` | 配送监控地图 | 出：地图聚合 |
| POST | `/merchant/landmarks/sync` | 平台点位同步 | 出 `{ok, count, inserted, updated, removed}` |
| POST | `/merchant/delivery/test-complete` | 测试完成配送（测试档） | 入 `{order_id?/batch_id?, status=3}` |
